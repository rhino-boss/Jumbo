## §2. 盤面結構

```text
Col:  0    1    2    3    4    5    6
      ↓    ↓    ↓    ↓    ↓    ↓    ↓
r0: [ ]  [ ]  [ ]  [ ]  [ ]  [ ]  [ ]
r1: [ ]  [ ]  [ ]  [ ]  [ ]  [ ]  [ ]
r2: [ ]  [ ]  [ ]  [ ]  [ ]  [ ]  [ ]
r3: [ ]  [ ]  [ ]  [W]  [ ]  [ ]  [ ]
r4:      [ ]  [ ]  [ ]  [ ]  [ ]
r5:           [ ]  [ ]  [ ]
r6:                [ ]
```

- 盤面為上寬下窄的六角倒三角形，每列有效格數為 [4, 5, 6, 7, 6, 5, 4]，共 37 格。
- 中心格 [Col 3, Row 3] 為固定 Wild 符號 [W]，永久存在、不被消除。
- 符號由上往下掉落（row 值小的為頂部），消除後空格由上方符號補位（Cascade）。
- 六角網格中，每格最多有 6 個相鄰格（上、下、左上、左下、右上、右下），連線判定遵循六角鄰接規則。

## §5. 核心遊戲流程（Base Game）

1. 玩家選擇押注並開始 Spin。
2. 盤面依輪帶（Reel Set）初始化，隨機選取 6 組輪帶之一生成符號；初始化後中心格固定替換為 Wild。
3. 補牌前，MY1 / MY2 / MY3 符號依序轉換為 3 種不同的 M 符號（轉換結果各不相同）。
4. 每列最多保留 1 個 C1，多餘的 C1 自動轉換為 M7。
5. 掃描盤面，找出所有「6 格以上相連的相同符號」群組（Cluster）。
6. 若有 Cluster 得分，依賠率表計算基礎分，再乘上當前 Wild 倍數（初始為 ×1）。
7. 消除中獎符號（中心 Wild 不消除）；解除被消除格的固定狀態。
8. Wild 倍數計數 +1，下一輪 Cascade 的倍數隨之升級。
9. 殘餘符號向下掉落補位（Cascade）。
10. 新補入的符號同樣先完成 MY 轉換與 C1 上限修正，再進行下一輪 Cluster 判定。
11. 若無 Cluster 可消除，檢查是否可觸發 Mega Eliminate 特色（見 §6.2）；有則繼續 Cascade，無則結束本輪。
12. 本輪結束後統計最終盤面的 C1 數量，達門檻則觸發 Free Game（見 §7）。

> **Base Game 每次 Spin 開始時，Wild 倍數計數歸零；Mega Eliminate 計數亦歸零。**

## §6. 核心特色

### 6.1 Wild 倍數乘數（Wild Multiplier）

- 中心格固定存在 1 個 Wild 符號，參與所有 Cluster 的連線判定（可橋接相同符號）。
- 本輪第 1 次 Cascade 計分時倍數為 **×1**，每完成一次有效消除（含或不含 Wild），倍數依序升級。
- 倍數序列：×1 → ×2 → ×4 → ×6 → ×8 → ×10 → ×12 → … 每次 +2，上限 **×100**。
- 倍數適用於**同一輪 Cascade 內的所有符號得分**，不僅限於含 Wild 的 Cluster。
- Base Game 每次 Spin 結束時倍數歸零；Free Game 期間倍數跨 Spin 累積（見 §7）。

**倍數對照表（按消除次數）：**

| 消除次數（本輪） | Wild 倍數 |
| --- | --- |
| 第 1 次 | ×1 |
| 第 2 次 | ×2 |
| 第 3 次 | ×4 |
| 第 4 次 | ×6 |
| 第 5 次 | ×8 |
| 第 6 次 | ×10 |
| 第 n 次（n ≥ 3） | ×(2n-2)，上限 ×100 |

### 6.2 Mega Eliminate 特色

**累積機制：**
- 每次消除中，Wild（中心格）所在的 Cluster 稱為「Wild 參與消除」。
- 每次 Wild 參與消除：`Mega 等級（Mega Level）` 增加 `min(Wild 參與的符號組數, 2)`。
- Mega Level 上限為 2；當 Mega Level 達到 2 時，`Mega 次數計數（Mega Count）` +1，Mega Level 重置為 0。
- Mega Count 上限為 3，此後不再累積。

**觸發與執行：**
- 當本輪無法再 Cluster 消除時，若 Mega Count > 0，則觸發 Mega Eliminate：
  1. 隨機抽選 1 個符號（M1–M7 依權重）作為本次 Mega 符號。
  2. 嘗試在盤面上放置 Mega Count 個「菱形區塊」（每個區塊覆蓋 4 格）。
  3. 所有已放置的格子轉換為同一 Mega 符號，並固定（不因後續 Cascade 移動）。
  4. Mega Count 扣除實際放置的區塊數；若仍 > 0，保留至下一輪 dry point 再試。
  5. 放置後繼續進行 Cluster 判定（新 Mega 符號可能形成新 Cluster）。
- 若無法放置任何區塊（全盤無合法位置），則結束本輪 Cascade。

**菱形區塊形狀（4 格）：**
- 中心點在 Col 0–2（左側）：方形排列 `(c,r)、(c,r+1)、(c+1,r)、(c+1,r+1)`
- 中心點在 Col 3–5（右側含中央列）：錯位排列 `(c,r)、(c,r+1)、(c+1,r-1)、(c+1,r)`
- 限制：不可覆蓋中心 Wild 格；不可覆蓋 Wild 或 C1 符號；各區塊不可重疊；需在六角有效格範圍內。

## §7. 免費遊戲（Free Game / FG）

### 7.1 觸發條件

- 每次 Spin 的 Cascade 全部結束後，統計最終盤面的 C1 數量。
- C1 達門檻即觸發 Free Game，並獲得對應局數：

| 最終盤面 C1 數量 | 獲得 Free Game 局數 |
| --- | --- |
| 3 | +8 局 |
| 4 | +10 局 |
| 5 | +15 局 |
| 6 | +20 局 |
| 7 | +30 局 |

### 7.2 Free Game 規則

- Free Game 使用 FG 專屬輪帶（FreeReel Set）與掉落表（FreeDropWeight）。
- **Wild 倍數跨 Spin 累積**：整段 Free Game 期間，Wild 倍數計數不歸零，隨每次有效消除持續升級，至 Free Game 全部結束後才重置。
- Mega Eliminate 機制於 Free Game 期間同樣適用。
- 每局 Free Game 結束後統計 C1 數量，達門檻則 Retrigger 加局（規則同觸發）。

### 7.3 Retrigger

- Retrigger 加局數與首次觸發相同（依 C1 數量對應上表）。

## §8. 邊界 / 例外情境（Edge Cases）

### 8.1 Wild 相關

- **8.1.1** Wild 只有 1 個，固定於中心格 [Col 3, Row 3]，不能被消除、不能移動。
- **8.1.2** Wild 可橋接不同的同色群組：同一次 BFS 中，Wild 可加入多個 Cluster（但在同一 Cluster 中只計算 1 次）。
- **8.1.3** Wild 倍數對所有符號均生效，不限於含 Wild 的 Cluster。

### 8.2 C1（Scatter）相關

- **8.2.1** C1 不參與 Cluster 得分、不被消除，在每次補牌後繼續保留在盤面。
- **8.2.2** 每列最多出現 1 個 C1；補牌後若同一列出現多餘 C1，後補入的 C1 自動轉為 M7。
- **8.2.3** FG 觸發判定時點為本次 Spin 的 Cascade 全部結束後。

### 8.3 MY（神秘符號）相關

- **8.3.1** MY1、MY2、MY3 三種神秘符號各自轉換為不同的 M 符號（轉換前先排除已用過的目標）。
- **8.3.2** 轉換於 Cluster 判定前完成，轉換後盤面才進行 Cluster 掃描。
- **8.3.3** 初始化（Reel Spin）與每次補牌（Drop）都會各自執行一次 MY 轉換，兩次轉換的目標符號獨立抽選。

### 8.4 Mega Eliminate 相關

- **8.4.1** Mega 符號放置時，若該格原本為 C1，則跳過不修改（C1 優先保留）。
- **8.4.2** 若 Mega Count 剩餘但無法放置任何區塊，本輪 Cascade 直接結束（不報錯，不重試整局）。
- **8.4.3** 已放置的 Mega 符號格子為固定格（Fixed），不會因 Cascade 掉落移動；被後續 Cluster 消除後，固定狀態解除。

### 8.5 Cascade 補牌相關

- **8.5.1** 補牌前記錄既有 C1 位置；補入新符號後，優先保留已有 C1，多出的 C1 轉為 M7。
- **8.5.2** 每次補牌根據當前消除次數重新選取 Drop 參數集（DropWeight 10 行 × 6 組），消除次數越高對應不同的符號組合。
