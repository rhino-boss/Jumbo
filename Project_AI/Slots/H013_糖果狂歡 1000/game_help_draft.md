# H013 Sugar Bonanza 1000 — Help Draft

## GAME META

- Game ID: `101001`
- PARsheet ID: `H0131`
- Board: 6 reels × 5 rows
- Modes: Normal Bet, Extra Bet (1.25x), Feature Buy (75x), Super Feature Buy (500x)
- Maximum advertised win: 25,000x Bet

> Internal note: the official game list currently records Feature Buy as 100x, while the legacy math and simulator use 75x. This draft follows the executable math. Remove this note from player-facing Help after confirmation.

## 简体中文

### 游戏玩法

游戏使用 6 轴 5 行盘面。同一种普通图标在盘面任意位置出现 8 个或以上即可中奖，无须相邻或连线。每次中奖后，中奖图标会消除，上方图标下落并补充新图标；只要形成新中奖，消除便会继续。

### 赔付表

| 图标 | 8-9 个 | 10-11 个 | 12 个以上 |
| --- | ---: | ---: | ---: |
| Heart | 10x | 25x | 50x |
| Square | 2.5x | 10x | 25x |
| Pentagon | 2x | 5x | 15x |
| Rectangle | 1.5x | 2x | 12x |
| Apples | 1x | 1.5x | 10x |
| Peaches | 0.8x | 1.2x | 8x |
| Watermelon | 0.5x | 1x | 5x |
| Grapes | 0.4x | 0.9x | 4x |
| Bananas | 0.25x | 0.75x | 2x |

### SCATTER 与免费游戏

主游戏的连续消除结束后，最终盘面出现 4、5 或 6 个 SCATTER，可分别获得 3x、5x 或 100x Bet，并触发 10 次免费游戏。免费游戏中，最终盘面出现 3 个或以上 SCATTER 可增加 5 次免费游戏；单次免费游戏最多 50 次。

### 倍数炸弹

免费游戏每次连续消除结束后，盘面上的倍数炸弹会分别抽取倍数并相加。若没有倍数炸弹，该次免费游戏使用 1x。该次免费游戏的全部中奖均乘以最终倍数。

### 押注选项

- EXTRA BET：投注提高至 1.25 倍，并使用提高特色触发机会的专用配置。
- FEATURE BUY：以 75x Bet 直接进入特色流程。
- SUPER FEATURE BUY：以 500x Bet 直接进入强化特色流程。

## English

### HOW TO PLAY

The game uses a 6-reel, 5-row grid. Eight or more matching regular symbols anywhere on the grid award a win; symbols do not need to be adjacent or connected. Winning symbols are removed, remaining symbols fall, and new symbols enter. Cascades continue while new wins are formed.

### PAYTABLE

| --- | ---: | ---: | ---: |
| Heart | 10x | 25x | 50x |
| Square | 2.5x | 10x | 25x |
| Pentagon | 2x | 5x | 15x |
| Rectangle | 1.5x | 2x | 12x |
| Apples | 1x | 1.5x | 10x |
| Peaches | 0.8x | 1.2x | 8x |
| Watermelon | 0.5x | 1x | 5x |
| Grapes | 0.4x | 0.9x | 4x |
| Bananas | 0.25x | 0.75x | 2x |

### SCATTER AND FREE GAMES

After all Base Game cascades finish, 4, 5 or 6 SCATTER symbols on the final grid award 3x, 5x or 100x Bet and trigger 10 Free Games. During Free Games, 3 or more SCATTER symbols on the final grid add 5 Free Games. A feature is capped at 50 Free Games.

### MULTIPLIER BOMBS

After all cascades in a Free Game finish, each Multiplier Bomb on the final grid draws a multiplier and the values are added together. If no bomb remains, the spin uses 1x. All wins from that Free Game are multiplied by the final value.

### BET OPTIONS

- EXTRA BET: increases the wager to 1.25x and uses a configuration with a higher feature chance.
- FEATURE BUY: enters the feature flow for 75x Bet.
- SUPER FEATURE BUY: enters the enhanced feature flow for 500x Bet.
