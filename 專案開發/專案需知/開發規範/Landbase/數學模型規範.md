# Landbase 轉製 數學模型規範

本頁說明 Landbase 轉製遊戲的數學模型與 Card System。新手體驗與系統限制見[系統機制](系統機制.md)。

## 1. 數學模型

### 1.1 必要內容

- 數學調性目前**沒有明確方向，由負責人自由發揮**（待討論）。
- 自由發揮不代表免記錄。負責人決定調性後，必須在數學模型的 `Game Description` 工作表與 `game_rule.md` 寫明：
  - 以原機數學為底還是重新設計；若以原機為底，記錄原機 RTP（Game List 的「RTP 版本」欄，例：84%）與調整到線上目標 RTP 的方式（改輪帶、改 Paytable、Card System 或其他）。
  - 波動度／最大倍數目標與 Hit Rate 目標。
  - 是否啟用 Card System；啟用時依第 2 章。
- 原機既有的 Bonus／Feature 玩法屬於 Game RTP 的一部分，不另拆 Bonus Game RTP（見第 1.4 節）。

### 1.2 模型命名

- Landbase 轉製遊戲的 ParSheet ID 仍為 `H<三位數字>1`；同一數學供多個 Game ID 使用時（如 `H0111` → 102001／102002），數學模型只建一份，Game ID 對應記錄於 `Game Description` 工作表與 Game List。

### 1.3 押注選項

押注金額由三個參數相乘（來源：H5 企劃書 `6.BetCurreny` 工作表）：

```text
押注金額 = 最小押分（credits）× Denom × Bet Multiplier
最小押分 = 100 credits；Denom = 0.002 → 1 倍押注 = 0.2
```

### 1.4 RTP 配置

```text
Total RTP = Link RTP + Game RTP + 新手體驗 RTP
```

- 轉製遊戲**不拆 Bonus Game RTP**；試算表「轉製遊戲」欄的 Bonus／Game 為同一合併欄位，原機的 Bonus／Feature 派彩全部歸入 Game RTP。
- 新手滾入彩池的 Increment 不計入新手 Total RTP；定義見第 1.5 節。
- RTP ＝ Total Win ÷ 實際 Total Bet；產品顯示可四捨五入，但計算用完整精度；各 Bet Mode 分母用該模式實際成本。

#### 1.4.1 NB／EB RTP 配置

| Player Profile | 押注層級 | 判定金額 | Link RTP | Game RTP | 新手體驗 RTP | Total (+機制) |
|---|---|---:|---:|---:|---:|---:|
| 新手 | 不分層級 | 全部 | 0.00% | 95.00% | 2.00% | 97.00% |
| 老手 | 高注 | `>= $2` | 2.00% | 95.00% | 0.00% | 97.00% |
| 老手 | 低注 | `< $2` | 0.00% | 97.00% | 0.00% | 97.00% |

- 新手**不分大小 Bet**，只有一套 RTP：Link 0% ＋ Game 95% ＋ 新手體驗 2% ＝ 97%。
- 老手 `>= $2` 的 Game RTP 比 `< $2` 低 2 個百分點，差額即 Link RTP，兩級 Total 相同。
- 新手 Link RTP 皆為 0%；新手 `>= $2` 的 Increment 只滾入彩池、不可中彩（見[系統機制](系統機制.md)的系統限制）。
- 本表於 2026-10-05 調整，與試算表 2026/05/14 版不同；試算表更新後兩者須一致。

#### 1.4.2 BF／SF RTP 配置

| Player Profile | 押注層級 | 判定金額 | Link RTP | Game RTP | 新手體驗 RTP | Total (+機制) |
|---|---|---:|---:|---:|---:|---:|
| 新手 | 不分層級 | 全部 | 0.00% | 96.50% | 0.00% | 96.50% |
| 老手 | 高注 | `>= $2` | 2.00% | 94.50% | 0.00% | 96.50% |
| 老手 | 低注 | `< $2` | 0.00% | 96.50% | 0.00% | 96.50% |

- BF／SF 的 Total RTP 為 **96.50%**（比 NB／EB 的 97% 低 0.5 個百分點），不含新手體驗。
- 新手 BF／SF 與老手 `< $2` 相同：Link 0% ＋ Game 96.5% ＝ 96.5%；**新手 BF 的 Link RTP 必為 0%**。
- 老手 `>= $2` 為 Link 2% ＋ Game 94.5% ＝ 96.5%。

### 1.5 彩金配置

Link 彩金為 Grand、Major 兩層累積彩池。**配置跟該遊戲所在的賭場一致**，不另訂（試算表 `彩金參數` 頁，2026/05/14）。

#### 1.5.1 Link 資格

「可滾 Inrc」表示該局押注會依 Increment 比例滾入彩池；「可拉 Link」表示該局有資格中 Grand／Major。兩者是不同的資格：

| 狀態 | 押注 | 可拉 Link | 可滾 Inrc |
|---|---|---|---|
| 新手 | `< $2` | 否 | 否 |
| 新手 | `>= $2` | 否 | 是 |
| 老手 | `< $2` | 否 | 否 |
| 老手 | `>= $2` | 是 | 是 |

- NB／EB 與 BF／SF 都適用上表；押注金額依第 1.6 節判定。系統限制另見[系統機制](系統機制.md)。
- Link RTP 與 Increment 由系統層依賭場設定，數學模型不得把彩金參數寫死在輪帶或 Paytable；模型只負責 Game RTP 與新手體驗，並在 `Game Description` 記錄採用的賭場與參數版本。
- 數學模型必須定義哪些派彩歸入 Link、哪些歸入 Game，不得重複計算。

#### 1.5.2 Link 彩金配置

| 賭場 | 級距 | 初始金額 | Startup% | Increment | RTP |
|---|---|---:|---:|---:|---:|
| Online（小平台） | Grand | $100,000 | 0.65% | 0.35% | 1.00% |
| Online（小平台） | Major | $20,000 | 0.50% | 0.50% | 1.00% |
| Online | Grand | $500,000 | 0.65% | 0.35% | 1.00% |
| Online | Major | $100,000 | 0.50% | 0.50% | 1.00% |

- **有 Link 的遊戲才依本表配置**，沒有 Link 的遊戲不用此配置。
- **賭場線上線下串連的配置不列入本表**：若要讓某賭場的線上與線下（實體機台）彩金串在一起，線上的配置必須與該賭場線下**一模一樣**；而每款 Landbase 轉製遊戲在賭場的配置都不同，無法訂一套共用值。目前只有 MFB（Okada）一家賭場，所以真要串時先以 MFB 的配置為準（例：Grand `$1,000,000`／Startup 1.10%／Increment 0.20%／RTP 1.30%；Major `$100,000`／0.50%／0.20%／0.70%）；之後若不再有這需求就用不到，因此**有要串時才依該遊戲、該賭場的配置另做**。

| 欄位 | 定義 |
|---|---|
| 初始金額 | 彩池開出後重置的起始金額（Start Up Pool） |
| Startup% | 押注中用來補足初始金額的比例；`Startup% = RTP − Increment` |
| Increment | 押注中滾入彩池、讓彩池累積上漲的比例（試算表的 Inrc） |
| RTP | 該級距的彩金 RTP；`RTP = Startup% + Increment` |

- Grand ＋ Major RTP ＝ Link RTP 2.00%；表中兩種配置的 Increment 合計皆為 0.85%。
- 平均開出金額：`Average Jackpot Hit Value = 初始金額 ÷ Startup% × RTP`。例：Online Grand ＝ $500,000 ÷ 0.65% × 1.00% ≈ $769,231。
- 試算表只給初始金額、RTP 與 Increment，Startup% 依上式推得；試算表改版時三欄一起更新。
- 新手 `>= $2` 的押注也會滾入 Increment，但新手不能中彩，所以新手的 Link RTP 為 0%。

### 1.6 Bet Mode

- 老手的押注層級只分 **`< $2`／`>= $2` 兩級**（低注／高注）；新手不分層級。
- NB／EB 以該模式的實際押注金額判定；BF／SF 以 **Feature 購買價格 ÷ Feature Price 倍數反推的基礎押注**判定，不用購買總價。
- 倍率上限依[系統機制](系統機制.md)的系統最大賠付反推；Newbie 上限 BG `30x`／FG `120x`。

## 2. Card System

### 2.1 設定結構

啟用 Card System 時，Oldhand 的押注層級只有兩套：

```text
oldhand
├─ normal_bet    → low_bet／high_bet → weight_bg／weight_fg
├─ extra_bet     → low_bet／high_bet → weight_bg／weight_fg
├─ buy_feature   → low_bet／high_bet → weight_fg
└─ super_feature → low_bet／high_bet → weight_fg
```

- `low_bet` 對應 `< $2`，`high_bet` 對應 `>= $2`；不得保留 `medium_bet`／`big_bet` 的空殼設定。
- 區間工作表（`Multiplier_Weight`、`Avg_Multi`、`Nature_Prob`）的 Oldhand 欄位依低／高注命名，例如 `NB_BG_Low`／`NB_BG_High`；Newbie 欄位不變。
- 是否啟用 Card System 隨第 1.1 節數學調性決定；未啟用時不得建立空白權重欄或 Card System 設定。
