# Mexico 數學模型規範（主流遊戲）

本頁說明墨西哥市場主流遊戲的數學模型，目前適用 H504、H506、H507；H512 轉換中（2026-11-16 起，狀態見第 2 節）；H503（王牌棋士）2026-11-18 轉換完成。玩家狀態、新手體驗、老手救援與系統限制見[系統機制](系統機制.md)。從菲律賓版轉成墨西哥版的步驟、規則與驗收，見[轉版指引](轉版指引.md)。

## 1. 數學模型

### 1.1 押注選項

押注金額由三個參數相乘：

押注金額 = 最小押分（credits）× Denom × Bet Multiplier
最小押分 = 100 credits；Denom = 0.002 → 1 倍押注 = 0.2

### 1.2 RTP 配置

```text
Total RTP = 新手體驗或老手救援 RTP + Link RTP + Bonus RTP + Game RTP
```

- Bonus RTP 是固定倍數、不累積的獎（彩金檔的 JP3／JP4）；Link RTP 是 Grand、Major 兩層累積彩池（第 1.3 節）。
- RTP ＝ Total Win ÷ 實際 Total Bet；產品顯示可四捨五入，但計算用完整精度；各 Bet Mode 分母用該模式實際成本。
- 新手體驗與老手救援由系統層給出，數學模型只負責 Game RTP 與 Bonus RTP。接 OP 彩金檔的遊戲（H506、H507），Bonus 以 OP 的設定為準，遊戲自己的文件沒有 Bonus 的計算。

#### 1.2.1 NB／EB RTP 配置

| Player Profile | 系統機制 RTP | Link RTP | Bonus RTP | Game RTP | 合計 |
|---|---:|---:|---:|---:|---:|
| 新手 | 新手體驗 2.00% | 該彩金配置的 Increment 合計 | 2.00% | 93.00% | 97.00%＋Increment |
| 老手無彩金 | 老手救援 1.00% | 0.00% | 2.00% | 94.00% | 97.00% |
| 老手有彩金 | 老手救援 1.00% | 2.00% | 2.00% | 92.00% | 97.00% |

- 沒有 Bonus、或 Bonus 無法與 Game 拆分的遊戲，Bonus 併入 Game：新手 Game 95.00%、老手無彩金 96.00%、老手有彩金 94.00%。
- 新手拉不到 Grand／Major，但押注會滾入 Increment，所以新手的 Link RTP **隨彩金配置變動**，等於該配置 Grand 與 Major 的 Increment 合計（第 1.3.2 節）：Grand 10 萬組與 Grand 50 萬組都是 0.85%。Game RTP 不隨彩金配置調整。表中新手的合計以有新手體驗 2% 的遊戲計；沒有新手體驗的遊戲（H504）少 2 個百分點。
- 老手有彩金＝押注 `>= 0.4` 且該遊戲開啟 Link；老手無彩金＝押注 `< 0.4`，或該遊戲／賭場未開 Link。
- 轉製遊戲的 Bonus＋Game 另有指定值（95.15%／96.50%／94.50%，見轉製規範第 1.4.1 節），不套用上面「Bonus 併入 Game」的數字。
- 新手體驗 2% 只適用有新手體驗的遊戲（系統機制第 2 節）：H506、H507 有；H504 的舊版新手救援已移除，沒有這 2%。

#### 1.2.2 Buy Feature RTP 配置

| 類別 | Link RTP | Bonus RTP | Game RTP | 合計 |
|---|---:|---:|---:|---:|
| 無彩金 | 0.00% | 4.00% | 92.50% | 96.50% |
| 有彩金 | 2.00% | 2.00% | 92.50% | 96.50% |

- **Buy Feature 不分新手／老手**，只分無彩金與有彩金。
- 沒有 Bonus、或 Bonus 無法與 Game 拆分的遊戲：無彩金 Game 96.50%、有彩金 Game 94.50%。
- Buy Feature 沒有新手體驗與老手救援。
- 新手不得拉 Link（系統機制第 4 節），所以新手購買 Feature 時 Bonus 與 Game 依「無彩金」列；押注不分高低都另外滾入 Increment（第 1.3.1 節）。
- 原遊戲已把新手 Buy Feature 另立一版的，維持原架構。
- H506 的 Link 與 Bonus 直接取自 OP 彩金檔，**以 OP 的設定為準**。OP 新手檔在 Buy Feature 押注鍵的設定是 Increment 0.85%＋Bonus 4%，Game 為 92.5%。

### 1.3 彩金配置

Link 彩金為 Grand、Major 兩層累積彩池。

#### 1.3.1 Link 資格

「可滾 Inrc」表示該局押注會依 Increment 比例滾入彩池；「可拉 Link」表示該局有資格中 Grand／Major。兩者是不同的資格：

| 狀態 | 押注 | 可拉 Link | 可滾 Inrc |
|---|---|---|---|
| 新手 | `< 0.4` | 否 | 是 |
| 新手 | `>= 0.4` | 否 | 是 |
| 老手 | `< 0.4` | 否 | 否 |
| 老手 | `>= 0.4` | 是 | 是 |

- 新手押注不分高低都滾 Increment（使用者 2026-11-19 確認；本專案自訂，菲律賓版轉製規範第 1.5.1 節的表寫的是新手 `>= $2` 才滾）。
- NB／EB 與 Buy Feature 都適用上表；押注金額依第 1.4 節判定。系統限制另見[系統機制](系統機制.md)。
- 數學模型必須定義哪些派彩歸入 Link、哪些歸入 Bonus、哪些歸入 Game，不得重複計算。
- 彩金參數的位置：H504 寫在 `H504_General_Info.xlsx › Jackpot Setting`；H506 用 `00_OP\01\JP0100A.xlsm`（新手）、`JP0100B.xlsm`（老手）、`JP0100C.xlsm`（老手無彩金）。檔內 `Parameter_List` 保留兩組，對應第 1.3.2 節的兩組配置，在 `Overview` 的 ID 選單切換：ID 2（Filbet 列）是 Grand 10 萬組，ID 28 是 Grand 50 萬組；兩組的押注鍵相同，同一押注鍵上只有 Grand、Major 的初始金額不同，其餘參數相同。菲律賓版其餘各賭場的列已移除（使用者 2026-11-11 指示「OP 的其他賭場列要移除」）。2026-11-11～19 檔內只有 ID 2 一組；ID 28 是 2026-11-19 依使用者指示（「要兩組彩金設定」）自菲律賓原檔原值加回的。
- H507 的數學模型不綁定彩金配置，套用第 1.3.2 節的任一組都成立。H507 的彩金全部接 OP 彩金檔（`00_OP\01\JP0100A／B／C.xlsm`，與 H506 相同，**以 OP 的設定為準**）：H507 的結果庫不含彩金的數學，只提供後端擲彩金用的打擊次數表（`board_scatter_by_weight_col_x1e10_ceil.json`）。OP 檔依「總押注是基礎押注的幾倍」分列設定，H507 用到 1、1.5、2、3（一般押注與三種 Extra Bet）和 75、120、300（四種購買）這幾列。Bonus 是 OP 的 JP3（Minor）與 JP4（Mini）：一般押注與 Extra Bet 合計 2%（Minor 50 倍 0.8%、Mini 10 倍 1.2%）；購買在新手檔與老手無彩金檔合計 4%、在老手檔合計 2%，與第 1.2.2 節一致。

#### 1.3.2 Link 彩金配置

| 組別 | 級距 | 初始金額 | Startup% | Increment | RTP | 平均開出金額 |
|---|---|---:|---:|---:|---:|---:|
| Grand 10 萬 | Grand | $100,000 | 0.65% | 0.35% | 1.00% | $153,846 |
| Grand 10 萬 | Major | $20,000 | 0.50% | 0.50% | 1.00% | $40,000 |

- **2026-11-25 使用者：墨西哥彩金一律用 Grand 10 萬組（Grand $100,000／Major $20,000）**；Grand 50 萬組不用。
- **有 Link 的遊戲才依本表配置**。H506 與 H507 接 OP 彩金檔，OP 彩金檔兩組都有（ID 2 是 10 萬組、ID 28 是 50 萬組，第 1.3.1 節）；H507 的模型不綁定配置；H506 先前登記為採用 Grand 10 萬組，OP 改成兩組都可選之後，各平台實際選哪一組由使用者指定，目前未定；H504 兩組都有（WTI01～03 為 50 萬組、WTI04～06 為 10 萬組；每組依序是新手、老手無彩金、老手有彩金）。
- 2026-11-16 使用者指示：Grand 100 萬組移除；Grand 10 萬組改回菲律賓版的設定（Major 初始金額 $20,000、Startup 0.50%／Increment 0.50%）。本節是目標規格；各遊戲檔案的修改狀態見第 2 節與轉換紀錄。

| 欄位 | 定義 |
|---|---|
| 初始金額 | 彩池開出後重置的起始金額（Start Up Pool） |
| Startup% | 押注中用來補足初始金額的比例；`Startup% = RTP − Increment` |
| Increment | 押注中滾入彩池、讓彩池累積上漲的比例（試算表的 Inrc） |
| RTP | 該級距的彩金 RTP；`RTP = Startup% + Increment` |
| 平均開出金額 | `初始金額 ÷ Startup% × RTP` |

- 彩金配置共兩組。Grand 的 Startup%／Increment 兩組都是 0.65%／0.35%；Major 兩組都是 0.50%／0.50%。
- Grand ＋ Major RTP ＝ Link RTP 2.00%。Increment 合計兩組都是 0.85%。
- Major 的初始金額兩組都是 Grand 的五分之一。
- 新手的押注不分高低都會滾入 Increment，但新手不能中彩。

### 1.4 Bet Mode

- Bet Mode 分一般押注（NB）、Extra Bet（EB）、Buy Feature（BF）。
- 老手的押注層級只分 **`< 0.4`／`>= 0.4` 兩級**（低注／高注）；新手不分層級。
- NB／EB 以該模式的實際押注金額判定；Buy Feature 以 **Feature 購買價格 ÷ Feature Price 倍數反推的基礎押注**判定，不用購買總價。
- Buy Feature 單次購買的實付金額上限 `$30,000`；超過的押注不開放、玩家端不顯示（[系統機制](系統機制.md)第 4 節）。超過上限的押注在數學文件裡已有的參數保留，沒有的不必補做。
- 新手單把上限 100×，只適用 NB 與 EB；其他倍率上限依[系統機制](系統機制.md)的系統最大賠付（`$3,000,000`）反推。
- H507 的 Bet Mode（0.3.1.1 版的名稱）：一般押注；三種 Extra Bet，總押注是基礎押注的 1.5 倍（Extra Bet）、2 倍（Ante Extra Bet）、3 倍（Super Extra Bet）；四種購買，價格是基礎押注的 75 倍（Basic Buy Feature）、120 倍（Plus Buy Feature）、120 倍（Fixed 6 Buy Feature）、300 倍（Fixed 18 Buy Feature）。結果庫內的代號依序是 `normal`、`eb1`、`eb3`、`eb2`、`buy`、`extra_buy`、`buy_x6`、`buy_x18`。

### 1.5 後端權重表的數值格式

- 本節只管**後端會使用的權重表**：後端或遊戲程式抽獎時讀進去的權重，例如輪帶或圖標的權重、彩金權重、輪盤權重（使用者 2026-11-16 指示）。
- 權重表內**不得出現負數或小數**，每一個權重都必須是**精確的整數**。由公式算出的值要在公式內用 `ROUND(…, 0)` 取整，不得留下浮點誤差（例如 `7499999.999999998`）。判定方式是儲存格實際存的值與它四捨五入後的值完全相等，不是畫面上看起來是整數。
- 權重不得用機率（0～1 的小數）的形式填寫，要寫成整數權重。
- 下列不是後端權重，不適用本節：押注與 Denom、以百分比表示的 RTP 與彩金參數、賠率與倍數、輪帶上的圖標編號與標記、用來推算權重的設計輸入（目標機率、放大倍率）、統計與驗算用的輸出格。設計輸入可以是小數，但由它算出來給後端讀的權重仍須在公式內取整。
