## §2. 盤面結構

```text
   R1   R2   R3   R4   R5   R6
┌────┬────┬────┬────┬────┬────┐
│ ◆  │    │    │    │    │ ◆  │  Row 1
├────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │  Row 2
├────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │  Row 3
├────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │  Row 4
├────┼────┼────┼────┼────┼────┤
│ ◆  │    │    │    │    │ ◆  │  Row 5
└────┴────┴────┴────┴────┴────┘
◆ = 四角特殊區域（R1／R6 的 Row 1 與 Row 5）
```

**Reel / Row**

| Reel | Row 數 | 位置索引 |
| --- | --- | --- |
| R1 ～ R6 | 各 5 | Row 1～5（上到下）；四角為 R1 Row 1、R6 Row 1、R1 Row 5、R6 Row 5 |

**得分方向**

- Pay Anywhere：每種一般符號在全盤（含四角）的總數達 8 顆以上即得分，依 8-9／10-11／12+ 計獎（沿用 H013）。
- 同一段可有多種符號同時得分，各自計獎後加總。

**補牌流程**

- 得分符號全部消除，同一輪剩餘符號往下掉落，空缺由該輪輪帶後續符號補上（沿用 H013）。
- **四角不參與掉落**：R1、R6 的符號掉落時跳過四角格（上方符號越過角落往下落、角落上方的空位照常補牌）；四角格消除後只補回四角符號（§5.2）。
- 補牌完成後重新判獎，直到沒有新的得分為止。

## §5. 核心特色

### 5.1 Cascade 消除（沿用 H013）

- 達門檻的符號整批消除、掉落補牌、重新判獎，直到沒有新的得分。

### 5.2 四角特殊區域：同一種符號

- 每次 Spin 開始時，四角同時出現**同一種一般符號**（四角符號，從 M1～M4、A～TE 中隨機抽出，權重 ⏳）。
- 四角符號照一般符號計入全盤數量、參與得分。
- 四角**不跟著整輪掉落**，也不會補入其他符號；四角格消除後只會補回同一種四角符號。
- 四角不會出現 C1。

### 5.3 四角補出倍數

- **四角的符號全部被消除時**（四角符號得分，四格同一段消除），四角各補出 **1 個 C2 倍數符號**（共 4 個）取代四角符號。
- 倍數值：BG 為 x1／x2／x3／x5（權重 85／10／4／1；H013 BG 沒有 C2 權重，照 FG 低表會讓 Demo RTP 遠超 500%，故改用小倍數）；FG 依該局高表／低表權重（沿用 H013）。
- 四角的 C2 **留到本次 Spin 結束**：之後不再補四角符號，本次 Spin 不會再觸發第二次四角倍數。
- 下一次 Spin 開始時，四角重新抽一種四角符號。

### 5.4 倍數結算（沿用 H013）

- 本次 Spin 連消全部結束後，盤面上所有 C2（含四角補出的 4 個）倍數加總，乘上本次 Spin 的總得分；沒有 C2 時以 x1 計。
- Base Game 原本沒有 C2，本作 BG 可經由四角得到 C2 倍數。

## §6. 免費遊戲（Free Spins / Free Game, FG）

### 6.1 觸發

- BG 連消結束後最終盤面 4／5／6 顆 C1，支付 Scatter 獎並觸發 10 局 FG（沿用 H013）。

### 6.2 FG 玩法

- 規則同 H013（2 局高表＋8 局低表、每局結束依盤面 C2 加總乘該局得分），另加四角特殊區域與四角倍數（§5.2、§5.3），每局四角重新抽符號。

### 6.3 Retrigger

- FG 單局結束時最終盤面 3 顆以上 C1，加 5 局（1 高表＋4 低表），總局數上限 50 局（沿用 H013）。

---

## §7. 核心遊戲流程（Base Game）

1. 玩家選擇押注並按 Spin；抽出本把的四角符號，四角放入該符號，其餘格子由輪帶停輪。
2. 統計每種一般符號全盤（含四角）數量，達門檻者得分。
3. 得分符號全部消除；若四角符號得分（四角全被消除），四角補出 4 個 C2。
4. 非四角格依輪掉落補牌（跳過四角格）；四角若是被消除但未觸發倍數的情況不存在（四角同符號，得分時必定四格一起消除）。
5. 重新判獎，重複 2～4，直到沒有新的得分。
6. 盤面所有 C2 倍數加總乘本次 Spin 總分（沒有 C2 以 x1 計）。
7. 依最終盤面 C1 數量支付 Scatter 獎並判定是否觸發 FG。

## §8. 押注模式

### 8.1 Extra Bet

- 費用 1.25x Bet，提高進入 FG 的機會（沿用 H013 ⏳）。

### 8.2 Buy Feature

- Buy Feature 100x、Super Buy Feature 500x，直接進入 FG（沿用 H013 ⏳）。

## §9. 邊界 / 例外情境（Edge Cases）

### 9.1 四角

- **9.1.1 四角永遠同符號**：同一把四角只會是同一種符號，或在觸發後全部是 C2。
- **9.1.2 四角得分必定四格同時消除**：Pay Anywhere 消除同符號全部格子，四角符號得分時四角一定一起消除，因此「四角都被消除」等同「四角符號得分」。
- **9.1.3 四角不掉落**：R1、R6 掉落補牌時跳過四角格，四角格不會被其他符號取代。
- **9.1.4 一把只觸發一次**：四角變成 C2 後留到 Spin 結束，不再觸發。
- **9.1.5 四角不出 C1**。

### 9.2 倍數

- **9.2.1 倍數延後結算**：連消全部結束才把盤面 C2 加總乘總分。
- **9.2.2 無 C2 以 x1 計**。

### 9.3 Scatter／FG

- **9.3.1 FG 觸發判定時點**：BG 連消結束後，依最終盤面 C1 數量判定。
- **9.3.2 FG 每局重抽四角符號**。
