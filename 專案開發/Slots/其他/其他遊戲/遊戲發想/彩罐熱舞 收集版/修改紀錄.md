# 彩罐熱舞 收集版 修改紀錄

只記錄數學調性的修改，依版本分、新到舊；每項後面括號為日期。

## v0（0.1.0.0）

1. 建立彩罐熱舞 收集版發想 demo：以 H026 92A（4.0.0.6）的 index 與 config 改；賠率、輪帶、金框、倍數權重、FG、Extra Bet 2x、Buy Feature 75x 全部沿用 H026；Card System 關。（11/10）
2. 金框改帶倍數或「收集」：每個金框 8% 改為收集（BG／FG／BF 同）；倍數金框自己消除不收集，消除收集時收當下盤面所有倍數（同段多個收集各收一次），被收的倍數留在盤面。（11/10）
3. 收集機率 8%（自然機率）：一般押注 411.2%（±30.0%，10⁶ 局）、Extra Bet 194.6%（±10.8%，10⁶ 局）、FG 1/41；Buy Feature 135.8%（±5.2%，10⁵ 局）。對照：收集 0%／5%／10%／20%／35% 時一般押注 85.7%／259.5%／506.5%／1,005.5%／1,368.9%；H026 原規則關卡片 1,851.7%。（11/10）
