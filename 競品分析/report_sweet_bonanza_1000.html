PP 攤平 xlsx：一列 = 一個 doSpin step，欄位就是封包 query string 拆開後的欄名。

欄位意義


4.4 判讀 / 觀察

  • NB-BG：(-1, 0] 佔 57.45%、(0, 1] 佔 22.40%，最高只到 (30, 35]（31.20x）。

一般遊戲完全沒有乘數炸彈，所以 BG 的上限被賠率表硬性封死在幾十倍 ——

這是本作與另外三款最大的結構差異（Gates SS 與 Sugar Rush 的 BG 都能開到四位數倍數）。

  • NB-FG：中位數 28.35x、平均 153.04x、最大 5,158.20x。57 場的分布橫跨 (1, 2] 到 (5000, 6000]。
  • BF-FG：中位數 220.50x、平均 573.84x、最大 9,395.40x，整條線比 NB-FG 右移約一個量級。
  • 三個門檻機率都要這樣讀：≥1000x 與 ≥5000x 在 30,893 局各只出現 1 次，≥10000x 是 0 次。

規則上限是 25,000x，所以 0% 的意思是「3 萬局的樣本規模不足以觀測這個量級」，

不是「這款開不出 10000x」。以單一 5,161x 的觀測外推，要穩定估計 ≥10000x 的機率，

樣本量至少要再放大兩個數量級。
