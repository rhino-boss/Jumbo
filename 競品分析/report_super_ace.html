1.2 統計方法

一行 JSONL = 一次付費 spin（method 全為 resolveSpinResponse）。

欄位意義
bet該次底注（本次側錄有 3.0 / 0.5 / 0.6 三種）
win該次下注的總得分（含一般遊戲與該回合觸發的整場免費遊戲）
is_bonus該回合是否觸發免費遊戲
combo_total該回合總消除次數（BG ＋ FG）
plate.plate盤面陣列：[0] 是一般遊戲盤面，[1..] 是各次免費轉
plate.plate[i].win該盤面得分；combo 是該盤面的逐次消除明細
isGold每格是否為金框（1 ＝金框）

BG / FG 拆分

```

BG 得分 = plate[0].win

FG 得分 = sum(plate[1..].win)

BG 連消 = len(plate[0].combo)

FG 轉數 = len(plate) - 1

```

sum(len(plate[i].combo)) == combo_total3,001 / 3,001 完全相符
