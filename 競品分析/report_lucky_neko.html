1.2 統計方法

一個 root_spin_id = 一次付費 spin。 Rounds 表已按此彙整，47,107 個 id 全部相異。

欄位意義
root_spin_id該回合的根 spin id（原始資料以 si_sid／si_psid 串接）
total_bet / base_bet該回合押注
total_win該回合總得分（＝base_game_win ＋ free_game_win）
bg_cascade_count一般遊戲的消除次數
free_spin_row_count該回合的免費轉數
reel_silver_counts每輪的銀框格數，如 [0, 3, 1, 2, 5, 1]
reel_symbol_counts每輪的可見格數（本作各輪高度可變）

交叉驗證

檢查結果
base_game_win ＋ free_game_win == total_win完全相符（殘差 0.0000）
BG combo 0 占比 ＋ Hit Rate100.036%（超出 0.036%，見下）
相異 root_spin_id == 回合數47,107 / 47,107
47,107 筆中有 39 筆 total_bet = 0（側錄開頭的斷頭回合），已排除，
實際付費回合 47,068。
