## §2. 盤面結構

```text
   R1   R2   R3   R4   R5   R6
   ↓    ↓    ↓    ↓    ↓    ↓
┌────┬────┬────┬────┬────┬────┐
│    │    │    │    │    │    │
├────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │
├────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │
├────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │
├────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │
└────┴────┴────┴────┴────┴────┘
```

- 每次 Spin 產生 30 個符號。
- 得分方向：不分方向，只統計整個盤面同一符號的總數量。
- 補牌方式：**消除後掉落補牌**。中獎符號消除後，同一輪未消除的符號依重力向下補位，剩餘空格由該輪掉落表抽出的新符號從盤面上方掉入。
- 補滿後重新判定所有一般符號，直到盤面不再出現新中獎，該次 Spin 才結束。
- Scatter（C1）、C2 與 C3 不屬於一般得分符號，不因 Any-8 規則自行消除，也留在原位不參與掉落補位。
- C1 出現後原地保留至該次 Spin 的所有 Cascade 結束；補位時同一輪不得再補入另一顆 C1，確保同一輪最多一顆 C1。

## §3. 符號類別

### 3.1 一般符號

| 類別 | 代碼 / 符號 |
| --- | --- |
| 高分符號 | M1 皇冠、M2 沙漏、M3 戒指、M4 聖杯 |
| 低分符號 | A 紅色寶石、K 紫色三角寶石、Q 金色六角寶石、J 綠色三角寶石、TE 藍色寶石 |

- 一般符號皆以 1×1 格出現，沒有任何替代關係。
- 每一種一般符號獨立統計盤面數量並判定 8–9、10–11、12+ 的賠付級距。
- **本作沒有 WW / Wild。** 輪帶載入時必須排除 WW，不得替代一般符號。

### 3.2 特殊符號

| 符號 | 出現位置 | 行為 |
| --- | --- | --- |
| **C1 / Scatter** | BG、FG、Buy Feature 入口盤面 | 最終盤面達門檻可觸發 FG；打擊 OP Jackpot 符號；不屬於一般 Any-8 得分符號，也不自行參與消除 |
| **C2 / Multiplier** | BG、FG 盤面 | 提供固定乘倍值；不屬於一般 Any-8 得分符號，也不自行參與消除；不隨 Cascade 升級 |
| **C3 / Super Multiplier** | BG、FG 盤面 | 提供乘倍值；每次中獎消除後提升一個倍數等級；不屬於一般 Any-8 得分符號，也不自行參與消除 |

## §5. 核心特色

### 5.1 C2／C3 倍數機制

- 輪帶與掉落表只產生倍數球候選符號 C2；每顆候選球再依 `weight_use_super_multiplier` 決定保留為 C2，或轉為 C3 / Super Multiplier。
- `weight_use_super_multiplier` 依該次 Spin 的初始盤面倍數球顆數選欄位；初始倍數球越多，使用 Super Multiplier 權重池的機率越高。初始盤面為 0 顆但 Cascade 後掉入倍數球時，使用 1 顆欄位；同一 Spin 後續掉入的倍數球沿用此欄位。
- C2 只由一般倍率池抽取，可抽出的倍率為 2x、3x、4x、5x、6x、8x；**10x 以上不得由 C2 一般倍率池抽出**。
- C3 只由 `weight_super_multiplier` 抽取，該權重表中所有有效倍率皆為 10x 以上。因此所有初始值為 10x 以上的大倍數球，必定來自 C3 / Super Multiplier 路徑。
- C2 出現後維持原倍數，不因 Cascade 升級。
- 同一 Spin 最終盤面有多顆 C2／C3 時，所有倍數**相加**，不相乘。
- BG 的 C2／C3 只作用於該次 Spin；FG 的 C2／C3 依 §6 累積至該場免費遊戲結束。
- 最終盤面沒有 C2／C3，且 FG 先前也沒有累積倍數時，等效倍數為 1x。

### 5.2 Cascade Multiplier：C3 每次消除升級

**每發生一次中獎消除，消除前已在盤面的每顆 C3 必定往後提升一個倍數等級；C2 不升級。**

- C3 的升級等級依數學模型 `Parameter / Multiplier Level` 順序：
  `2 → 3 → 4 → 5 → 6 → 8 → 10 → 12 → 15 → 20 → 25 → 50 → 100 → 250 → 500 → 1000 → 2500`。
- C3 的初始值至少為 10x，升級後可到達未直接配置抽取權重的較高級距。
- 同一個 Cascade 即使同時有多種符號中獎，也只算一次消除事件，因此每顆 C3 只升一級。
- 該次消除後新掉落進盤面的 C3 不追溯升級；必須等下一次中獎消除才升級。
- C3 升至 **2500x** 後，後續 Cascade 維持 2500x。
- C2 與 C3 本身皆不消除，會留在盤面供後續 Cascade 及最終結算使用。

### 5.3 場景表混合（Scene Mixture）

- BG、FG 與 Buy Feature FG 各由兩張子輪帶表組成一個場景，兩張表使用同一份掉落表。
- **BG**：每一次付費 Spin 依 `base_reel_weights` 獨立抽一張子表。
- **FG／Buy Feature FG**：每一次免費 Spin 依 `free_table.weights` 獨立抽一張子表；不是整場 FG 固定一張表。
- 抽表結果只影響該次 Spin 的初始盤面來源，不改變判獎規則、賠率、消除流程或 Feature 條件。
- 兩張子表的符號配置使兩者混合後的每輪符號占比與掉落占比維持設計值。

### 5.4 OP Jackpot

- C1 Scatter 除處理自身賠付與 FG／Retrigger 外，也會打擊 OP Jackpot 符號。
- OP Jackpot 的內容與派彩不影響 §4 的一般符號與 Scatter 賠付。

## §6. 免費遊戲（Free Spins / Free Game, FG）

### 6.1 觸發

- BG 最終盤面出現 **4 個以上 C1** 時觸發。
- 4、5、6 個 C1 均取得 **15 Spins**，並另依 §4 支付 Scatter 獎金。
- 觸發判定在所有 Cascade 結束後執行。

### 6.2 FG 玩法

- FG 中每次 Spin 仍使用 Any-8 與 Cascade，每一轉依 §5.3 獨立抽場景子表。
- 每次 FG Spin 最終盤面的所有 C2／C3 值，不論該次 Spin 是否有一般符號中獎，均加入 FG 累積倍數。
- 本次新取得的 C2／C3 倍數立即加入並作用於本次 Spin；FG 累積倍數跨 Spin 保留，直到整場 FG 結束才清除。
- 設 `R` 為本次 Spin 所有 Cascade 的一般符號基本獎金總和、`M_prev` 為 Spin 開始前的 FG 累積倍數、`M_now` 為本次最終盤面 C2／C3 倍數總和、`S` 為 Scatter 獎金，則：

  `M_total = M_prev + M_now`

  `本次 FG 獎金 = R ×（M_total > 0 時使用 M_total，否則使用 1）+ S`

- Scatter 獎金 `S` 不乘 C2／C3 倍數。
- FG 最多 **50 Spins**。
- FG 內同樣套用 C3 每次 Cascade 往後升一級；C2 不升級。C2 直接抽取上限為 8x，C3 可升至 2500x。

### 6.3 Retrigger（加局）

- FG 最終盤面出現 **3 個以上 C1** 時增加 5 Spins。
- 末場 FG 若符合條件，仍可加局，但總場次不得超過 50 Spins。
- 4–6 個 C1 同時支付 §4 定義的 Scatter 獎金。

## §7. 核心遊戲流程（Base Game）

1. 玩家選擇押注模式與 Bet。
2. 依該模式的場景權重抽出本次 Spin 使用的子輪帶表（§5.3），再產生 6 輪盤、每輪 5 格的初始盤面。
3. 對每一種一般符號統計盤面數量；本作沒有 WW，不加入任何替代符號數量。
4. 合計達 8 個以上的符號依 §4 給獎；同一盤面可有多種一般符號同時中獎。
5. 所有中獎一般符號一併消除，盤面掉落並由該表掉落表補入新符號。
6. 每發生一次中獎消除，消除前已在盤面的每顆 C3 往後升一個倍數級距；C2 倍數不升級。
7. 若補牌後仍有新中獎，回到第 3 步重複判定、給獎、消除與補位。
8. 所有 Cascade 結束後結算 C2／C3 總倍數、Scatter 獎金、OP Jackpot 打擊與 FG 觸發。

---

## §8. 押注模式

### 8.1 Extra Bet

- 成本：2 × Normal Bet；獎金仍以玩家所選基礎 Bet 計算。
- 效果：Free Game 觸發機率為 Normal Bet 的 5 倍。
- 與 Normal Bet 的差異只在扣款與 FG 觸發機率，判獎、賠率、Cascade 與 FG 規則完全相同。

### 8.2 Buy Feature（購買特色）

- 成本：100 × 玩家所選基礎 Bet；FG 獎金仍以該基礎 Bet 計算。
- Buy Feature 的入口盤面使用專用輪帶 `BF_Symbol`，保證 R2～R5 各出現一顆 C1，因此入口盤面必定取得 4 顆以上 C1 並進入一般 FG。
- **入口盤面不產生任何 BG 得分。** `BF_Symbol` 的每 5 格視窗內同一般符號不重複，單一一般符號在盤面最多 6 個，數學上不可能達到 Any-8 門檻。
- 入口盤面不配置 C2，因此不會在入口取得倍數球。
- 進入 FG 後使用與自然觸發完全相同的 FG 規則。
- 本作沒有 Super Feature；Bet Mode 3 不可使用。

## §9. 邊界 / 例外情境（Edge Cases）

### 9.1 Wild 相關

- **本作沒有 WW / Wild。** 不得替代一般符號，也沒有 WW→C2 的轉換。

### 9.2 倍數機制相關

- **多顆倍數符號**：同一盤面的 C2／C3 倍數採加總，不相乘。
- **C2／C3 不消除**：兩者都不屬於 Any-8 得分符號，周圍符號消除時留在盤面原位。
- **C3 升級**：只有 C3 在每次中獎消除後升一級；C2 維持出現時的倍數。
- **單顆上限**：C2 直接抽取上限為 8x；C3 初始值至少 10x，並可逐級升至 2500x。
- **10x 分界**：10x 以上的倍率只能由 C3 路徑取得；C2 一般倍率池不得配置 10x 以上的權重。
- **FG 累積**：最終盤面的 C2／C3 均加入 FG 累積倍數，FG 結束後歸零。

### 9.3 Scatter 相關

- **Scatter 不參與 Any-8**：C1 原地保留至所有 Cascade 結束後再判定。
- **FG 判定點**：每次 Spin 所有 Cascade 結束後，統計最終盤面 C1。
- **打擊 OP Jackpot**：C1 除自身賠付與 FG／Retrigger 外，也會打擊 OP Jackpot 符號。
- **同轉輪最多一個**：Scatter 在相同轉輪最多只會出現一個。
- **輪帶間距**：同一張輪帶的同一 Reel 中，任兩個 C1 的輪帶位置索引距離至少為 6；輪帶視為首尾相接，尾端至起點的循環距離也必須符合此限制。

### 9.4 Free Game 相關

- **末場加局**：最後一場若取得 3 個以上 C1，仍立即增加場次。
- **場次上限**：總 FG 場次上限為 50 Spins。
- **FG 倍數累積**：整場 FG 的多顆 C2／C3 加總累積不另設上限；單顆 C3 上限為 2500x。
- **場景抽表**：每一次免費 Spin 獨立抽場景子表，Retrigger 取得的場次同樣逐轉抽表。

### 9.5 Buy Feature 相關

- **自然觸發一致性**：Buy 進入 FG 後使用與自然觸發相同的 FG 規則。
- **入口 C1 數量**：`BF_Symbol` 保證 R2～R5 各一顆 C1，R1 與 R6 不強制，因此入口最終 C1 數量為 4～6 顆。
- **入口不派 BG 獎**：入口盤面只可能取得 Scatter 賠付，不會有一般符號派彩。

### 9.6 Pay Anywhere / Cascade 相關

- **多種符號同時中獎**：每種符號獨立判定並相加基本獎金，再套用 C2／C3 規則。
- **無 Wild 計數**：Any-8 只統計該一般符號本身，不加入任何替代符號。
- **Cascade 終止條件**：直到盤面沒有任何一般符號達到 8 個以上。
- **Cascade 上限**：單次 Spin 的 Cascade 次數上限為 100。

### 9.7 押注與帳務相關

- **Bet 基準**：Normal Bet、Extra Bet 與 Buy Feature 的賠付皆以玩家所選基礎 Bet 為計算基準；Extra Bet 僅將扣款提高為 2 倍，Buy Feature 僅將扣款提高為 100 倍。
- **押注層級**：NB／EB 以實際模式押注金額判定小／中／大 Bet；Buy Feature 以購買價格除以 100 反推的基礎押注判定。
