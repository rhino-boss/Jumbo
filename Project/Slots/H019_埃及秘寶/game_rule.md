## §2. 盤面結構

```text
       R1   R2   R3   R4   R5   R6
     ┌────┬────┬────┬────┬────┬────┐
  1  │    │    │    │    │    │    │
     ├────┼────┼────┼────┼────┼────┤
  2  │    │    │    │    │    │    │
     ├────┼────┼────┼────┼────┼────┤
  3  │    │    │    │    │    │    │
     ├────┼────┼────┼────┼────┼────┤
  4  │    │    │    │    │    │    │
     ├────┼────┼────┼────┼────┼────┤
  5  │    │    │    │    │    │    │
     └────┴────┴────┴────┴────┴────┘
```

每次 Spin 產生 30 個符號。得獎符號消除後，剩餘符號向下掉落，空位依該次使用的輪帶繼續補入；補滿後再次判定，直到沒有新獎項。

---

## §3. 符號類別

| 代碼 | 類別 | 規則 |
| --- | --- | --- |
| M1、M2、M3、M4、A、K、Q、J、TE | 一般得分符號 | 各自與 Wild 合計數量達門檻時得獎。 |
| WW | Wild | 可替代所有一般得分符號，不替代 C1 或 C2。**只有參與中獎消除的 Wild 會轉成 C2。** |
| C1 | Scatter | BG 最終盤面 4 個以上觸發 FG；FG 最終盤面 3 個以上 Retrigger。 |
| C2 | 倍數符號 | 留在盤面、不參與一般符號消除；最終盤面上各 C2 倍數相加形成總倍數。 |

## §4. 賠率表

一般押注以 100 Credit 為 1× Bet。下表已換算為總押注倍數：

| 符號 | 8–9 個 | 10–11 個 | 12 個以上 |
| --- | ---: | ---: | ---: |
| M1 | 10× | 25× | 50× |
| M2 | 2.5× | 10× | 25× |
| M3 | 2× | 5× | 15× |
| M4 | 1.5× | 2× | 12× |
| A | 1× | 1.5× | 10× |
| K | 0.8× | 1.2× | 8× |
| Q | 0.5× | 1× | 5× |
| J | 0.4× | 0.9× | 4× |
| TE | 0.25× | 0.75× | 2× |

| C1 數量 | 獎金 | 免費遊戲 |
| --- | ---: | ---: |
| 4 | 3× | 15 Spins |
| 5 | 5× | 15 Spins |
| 6 | 100× | 15 Spins |

同一盤面可有多個一般符號同時得獎，各獎項分別計算後相加。

## §5. 中獎、消除與 Wild 轉換

1. 對每一種一般符號，計算「該符號數量 + WW 數量」。
2. 合計數量達 8 個以上時，依 §4 對應區間給獎。
3. 同一盤面所有得獎一般符號一併消除。
4. 參與該次中獎判定的 WW 不消失，改為 C2 並留在盤面。
5. C1、既有 C2 與未得獎的一般符號保留；空位補入新符號後再次判定。
6. 最終沒有新獎項時，才結算 C1 與 C2。

---

## §6. C2 倍數功能

C2 可直接出現在輪帶，也可由參與中獎消除的 WW 轉換而來。每一個 C2 獨立抽取倍數值，可能值為：

`2、3、4、5、8、10、12、15、20、25、50、100、150、200、250、500、1000`

每次 Spin 先依 `Parameter` 抽選 C2 權重類型：

| 類型 | 說明 |
| --- | --- |
| Normal | 區分直接出現 C2 與 Wild 轉成 C2 的實際權重表。 |
| Super | 所有 C2 使用 Super 權重表。 |
| Ultimate | 所有 C2 使用 Ultimate 權重表。 |

最終盤面所有 C2 倍數值相加；若沒有 C2，總倍數視為 1。該 Spin 的消除總獎金乘上總倍數，C1 獎金不乘 C2 倍數。

**本版 Simulator 依使用者指定只保留 Normal／Super／Ultimate 權重選擇，不使用 xlsx 流程頁另載的 Bad 權重切換、FG 表強制替換或整場重抽控制。**

## §7. Free Game

- BG 最終盤面出現 4、5 或 6 個 C1 時，均取得 15 次免費遊戲。
- Normal／Buy Feature 使用 FG_Symbol 系列輪帶；Super Feature 使用 SF_Symbol 系列輪帶。
- 初始 15 Spins 的輪帶場次配置由 `Parameter` 的 Free Table Initial 决定。
- FG 單次 Spin 最終盤面出現 3 個以上 C1，增加 5 Spins；新增輪帶配置由 Free Table Retrigger 決定。
- 一場 FG 最多 50 Spins。
- FG 中取得的 C2 倍數累積至該場免費遊戲結束。

## §8. 押注模式

| 模式 | 成本 | 初始盤面 | 免費遊戲輪帶 |
| --- | ---: | --- | --- |
| Normal Bet | 1× Bet | 依 Parameter 的 BG 四組權重選表 | FG 四組 |
| Buy Feature | 100× Bet | BF_Symbol，保證以前四輪 C1 觸發 FG | FG 四組 |
| Super Feature | 500× Bet | BF_Symbol，保證以前四輪 C1 觸發 FG | SF 四組；C2 倍數最小值為 10× |

## §10. 卡片系統（Simulator 結果篩選）

卡片系統不改變盤面、輪帶、賠付或 C2 規則，而是在每局完成後檢查結果；不符合抽中卡片時，以相同卡片重跑該局。

- 卡片與權重來源：xlsx `Multiplier_Weight`。
- 玩家 Profile：Normal Bet 可選 `Newbie` 或 `Oldhand`。
- Normal BG：`range` 卡檢查 BG 獎金倍率；`free_game` 卡要求該局觸發 FG。
- Normal FG：觸發 FG 後依對應 FG 卡檢查整場 FG 獎金倍率。
- Buy／Super Feature：分別使用 `Weight_BF_FG`／`Weight_SF_FG`，檢查 BG＋FG 整包獎金。
- 區間採 `(min, max]`；卡片倍率分母一律使用 Normal Bet 基準押注 100 Credit。
- 同一局最多重跑 5000 次；達上限時保留最後結果並記錄失敗原因。
- 報表記錄 profile、總重試、平均重試、上限命中與各類失敗次數；檔名最後加 `_card`。
