## Overview

### 比較基準

| 項目 | Gates of Olympus 1000 | H027 現在版本 |
|---|---|---|
| 來源 | `game_responses-gates of olympus 1000.xlsx` | `config_92A.js` + `Simulator.py` |
| 版本 | 競品實際 Response 樣本 | `H0271` / `0.0.0.1` |
| 樣本 | 7,075 個付費 Spin、20 場 FG、315 個 FG Spin | 10,000,000 個 Normal Bet Round、14,415 場 FG、217,645 個 FG Spin |
| Card System | 競品實際遊玩資料 | 關閉 |
| Bet Mode | 一般投注 | Normal Bet，Bet Multi 1 |
| 輪帶 | 實際盤面觀測分布 | `BG_Symbol`、`FG_Symbol`；R1～R6 各 300 格 |

H027 數值為本次 10,000,000 局模擬樣本，不是理論精確值。競品 FG 只有 20 場，FG RTP、FG 平均倍數與最大得分的波動會明顯高於 H027 樣本。

## 符號分布

競品依 Response 盤面拆成 R1～R6；每輪每個盤面有 5 格。H027 初始盤面依每輪 300 格輪帶計算；掉落改用 `AH:AM` 的獨立 Symbol 權重，每輪總權重 1,000,000。`Multiplier` 對應 H027 `C2`；H027 `C3` 自然出現率為 0，競品沒有對應符號，因此不列入。
