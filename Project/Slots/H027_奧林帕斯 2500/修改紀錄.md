# H027 修改紀錄

## 2026-08-31：移除共用加權百分位（linked stop）

### 修改目的

- 與 SPS 的 `101027 H0271 核對模型後` 報表逐項核對後，確認 linked stop 是兩邊唯一的機制性差異：
  SPS 的 `gameSetting` 沒有對應欄位、`screenGenerator` 也是六輪各自抽停點，這個機制無法移植。
- 用 config 權重直接反推可以完全對帳：混合後理論 BG／FG 初始命中率 28.89%／44.10% 對上本地實測
  29.15%／44.13%；純獨立抽停點理論 28.21%／39.07% 對上 SPS 實測 28.42%／38.91%。

### 實際變更

- `Versions/0.0/Source/model_sync.py`（現行轉檔實作）：移除寫入 `linked_stop_*` 的設定區塊。
- `config.js`、`config_92A.js`、`config_94A.js`：每張輪帶移除
  `linked_stop_denominator`／`linked_stop_weight`／`linked_stop_offsets`（6 張 × 3 = 18 個欄位／檔）。
- `Simulator.py`：移除 `LINKED_STOP_*` 全域陣列與 `generate_board()` 的共用百分位分支，
  改為六輪一律各自依 Symbol Weight CDF 抽停點。
- `index.html`：同步移除 demo 的 linked stop 分支。
- 未改動輪帶符號、輪長、Symbol Weight、掉落來源、C2／C3 權重與賠率表。
