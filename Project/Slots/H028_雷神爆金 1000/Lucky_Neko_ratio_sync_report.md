# Lucky Neko 比例同步報告

## 同步範圍

| Lucky Neko 分頁 | 使用資料 | config 目標 |
|---|---|---|
| `SymbolOcc_Init` | BG／FG 初始畫面 R1～R6 的 Symbol 比例 | `BaseGameSymbol1`、`FreeGameSymbol1` |
| `SymbolOcc_Drop` | BG／FG 掉落 R1～R6 的 Symbol 比例 | `BaseGame1Drop1`～`Drop5`、`FreeGame1Drop1`～`Drop5` |
| `Silver_Init` | BG／FG 初始畫面每輪銀框顆數分布 | 初始輪帶 ID 13～23 |
| `Silver_Drop` | BG／FG 掉落每輪銀框顆數分布 | Drop 權重 ID 13～23 |
| `ExtraReelSame` | BG／FG R7 同符 rate | 初始輪帶 R7 與 Drop R7 |

## 版本與檔案

- config：`config_92A.js`
- xlsx：`Source/H028192A.xlsx`
- 同步版本：`2.0.0.6`
- 啟用參數組：`ReelWeight = [4000, 0]`、`FreeReelWeight = [15000, 0, 0]`、`FreeTriggerReel = [12000, 0, 0]`
- BG R1～R7：每輪 150 格。
- FG R1～R7：沿用既有工作表配置，每輪 121 格。

## 換算方式

1. `SymbolOcc_Init`、`SymbolOcc_Drop` 的 ID 0～12 為折回銀框後的本體 Symbol 比例。
2. 銀框只拆分 M1～TE（ID 2～12），對應 config 的 ID 13～23；WW、C1 不拆銀框。
3. 初始銀框占比＝`Silver_Init` 每輪銀框期望顆數 ÷ `ReelHigh_Init` 每輪期望 Symbol 數。
4. 掉落銀框占比＝`Silver_Drop` 每輪銀框期望顆數 ÷ 5 格主輪高度。
5. `ExtraReelSame` 的 `rate_BG`／`rate_FG` 分別正規化為 R7 分布；來源為非零的 Symbol 在 R7 至少保留一格。
6. `SymbolOcc_Drop` 沒有依 Combo 分層，因此相同目標分布套用至 Drop1～Drop5。
