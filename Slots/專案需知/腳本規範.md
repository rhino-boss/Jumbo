# 腳本規範

本文件屬於 `Slots/專案需知/` 專案需知文件集，總覽、共通原則與完成條件見 [_README.md](_README.md)。

內容涵蓋：表演腳本（預錄結果腳本）的用途、清單結構、格式欄位、挑選規則、權重整合與交付檢查。

## 1. 用途與定位

表演腳本是**預先錄製的 RNG 序列與固定結果**，供前端在特定情境直接重放，用於新手體驗、Buy Feature 展示與 Free Spin 系統等。

- 腳本只影響「被挑中的那幾局」的表演結果，**不改變真實遊戲的數學模型、Config 與派彩公式**。
- 每支腳本的 RNG 序列必須能在該遊戲的正式輪帶／掉落設定下重放出相同結果；輪帶或掉落權重改版時，必須驗證既有腳本仍可重放，否則重錄。
- 腳本表以遊戲為單位維護（每款一張，依 RTP 版型分組），欄位格式見第 3 節。

## 2. 腳本清單結構

依遊戲實際支援的押注模式建立；遊戲不支援的模式不得出現對應腳本。

| 類別 | 腳本 | 支數 | 說明 |
| --- | --- | --- | --- |
| 新手體驗 | `NB Free Game A／B` | 2 | 觸發 FG 的完整表演，固定總倍率 |
| 新手體驗 | `NB Jackpot Game A／B` | 2 | OP Jackpot 小遊戲體驗，固定總倍率 |
| 新手體驗 | 其他押注模式（EB 等）之 Free Game／Jackpot Game A／B | 依支援 | 遊戲支援該模式才建立 |
| Buy Feature | `BF A1～A3`、`BF B1～B3` | 每版型 3 | 高／中／低 RTP 三檔＋抽選權重（見 4.2） |
| Free Spin 系統 | `0-1x 腳本`＋`9x 腳本 ×10` | 11 | 新手 NB 免費遊戲系統（見 4.3） |

## 3. 格式欄位

每支腳本一列，欄位固定：

| 欄位 | 內容 |
| --- | --- |
| 腳本名稱 | 類別＋模式＋編號（例：`Buy Feature A2`） |
| RNG | 預錄的 RNG 序列（逗號分隔） |
| Multi | 該腳本的總得分倍率（以該模式單注為底） |
| RTP | `Multi ÷ 押注 × 100%` |
| 抽選權重 | 同組腳本間的抽選權重 |
| 押注 | 該模式的成本倍數（NB＝1、BF＝購買價倍數） |

## 4. 挑選規則

### 4.1 新手體驗

- 每支權重＝1、押注＝1；同名 A／B 兩支等權重擇一。
- 總倍率為體驗設計值，製作前與使用者確認（參考值：Free Game 12x、Jackpot Game 10x）。

### 4.2 Buy Feature

- 每個版型三支：高／中／低 RTP 各一，另配抽選權重；押注＝Buy Feature 價格倍數。
- **加權整合必須等於 96.00%**：`Σ(RTP × 權重) ÷ Σ(權重) = 96.00%`。
- 三檔 RTP 先定，權重由上式解出並整數化；解出後驗算到小數 2 位精確。
- 參考例（前作 92 版）：105.67%×800＋88.80%×200＋81.53%×435 → 加權 96.00%。

### 4.3 Free Spin 系統

- 適用新手 NB 的免費遊戲段（一段 10 把）。
- 挑法：10 把中**挑一把跑 `0-1x` 腳本、挑一把跑 `9x` 腳本**，其餘各把不中獎。
- `9x` 腳本固定 **10 支**，**抽選權重鎖死全部＝1**（等權重擇一），不得調整。
- 整段合計約 10x（參考值：0-1x＝44%＋9x＝955.56% → 999.56%）。

### 4.4 版型與共用

- 腳本表依 RTP 版型分組（例：92 版一張）；同一支 RNG 序列若在多個 RTP 版可重放出相同結果，可跨版共用並註記。
- 大額投注使用獨立模型（`_Bet100`）的遊戲：腳本倍率不得超過該模型的倍率上限（例：FG 上限 2,000x）。

## 5. 製作前必須與使用者確認

1. 新手體驗涵蓋哪些押注模式（NB 以外是否含 EB／BF 體驗）。
2. 各體驗腳本的目標倍率（Free Game／Jackpot Game）。
3. 腳本表做哪些 RTP 版型、是否跨版共用。
4. Buy Feature 三檔 RTP 的目標值（權重由 96% 約束解出）。

## 6. 交付檢查

- [ ] 腳本清單依第 2 節結構建立，未支援的模式沒有腳本。
- [ ] 每支 RNG 序列已在正式 Config 下重放驗證，結果與表列 Multi 一致。
- [ ] Buy Feature 各版型加權整合＝96.00%（小數 2 位精確）。
- [ ] Free Spin 系統：`9x` 腳本 10 支、權重全部＝1；0-1x 與 9x 各佔一把、其餘不中獎。
- [ ] 腳本倍率未超出該模式（含 `_Bet100` 模型）的倍率上限。
- [ ] 輪帶／掉落改版後已重新驗證重放（或重錄）。

## 7. 範例：H028 雷神爆金1000（101016）

支援 NB＋BF（無 Extra Bet），FG 觸發＝4 SC＝10 把：

| 類別 | 腳本 | 支數 |
| --- | --- | --- |
| 新手體驗 | NB Free Game A／B、NB Jackpot Game A／B | 4 |
| Buy Feature | BF A1～A3＋權重、BF B1～B3＋權重（押注 75；加權＝96.00%） | 6 |
| Free Spin 系統 | 0-1x ×1＋9x ×10（權重全鎖 1） | 11 |
| 合計 |  | **21** |

無 Extra Bet，故不建立 EB 系列腳本；FG 觸發 10 把與 Free Spin 系統的「10 把挑法」一致。
