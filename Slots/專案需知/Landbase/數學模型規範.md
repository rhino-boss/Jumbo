# Landbase 轉製 數學模型規範

本文件屬於 `Slots/專案需知/Landbase/`，適用於 **Landbase 轉製遊戲**（實體機台數學轉製為線上版，Game List 備註「線上-Landbase轉製遊戲」者，如 102xxx／105xxx）。

本文件採**差異式**撰寫：只列 Landbase 產線與 Omniplay 不同或新增的規則；**凡本文件未覆寫的條款，一律沿用 Omniplay 的 [數學模型規範.md](../數學模型規範.md)**（命名、版本、工作表、卡片區間、PARsheet、程式化修改 XLSX 等）。兩者衝突時以本文件為準。

RTP 配置與系統機制的正式來源為 Google 試算表 [RTP 設定](https://docs.google.com/spreadsheets/d/1Qk66cM8iZqyEhr23nsnxiDXOHj8CGNji--sedOHF0F8/edit?gid=386193409)（`數值設定`、`彩金參數` 兩頁）。本文件引用的是 **2026/05/14「全平台」版的「轉製遊戲」欄**；試算表更新時必須同步修訂本文件並記錄日期。

## 1. 數學調性

- 目前**沒有明確方向，由負責人自由發揮**（待討論，見第 7 節）。
- 自由發揮不代表免記錄。負責人決定調性後，必須在數學模型的 `Game Description` 工作表與 `game_rule.md` 寫明：
  - 以原機數學為底還是重新設計；若以原機為底，記錄原機 RTP（Game List 的「RTP 版本」欄，例：84%）與調整到線上目標 RTP 的方式（改輪帶、改 Paytable、Card System 或其他）。
  - 波動度／最大倍數目標與 Hit Rate 目標。
  - 是否啟用 Card System；啟用時依第 5.2 節。
- 原機既有的 Bonus／Feature 玩法屬於 Game RTP 的一部分，不另拆 Bonus Game RTP（見第 2 節）。

## 2. RTP 配置

### 2.1 配置口徑

```text
Total RTP = Link RTP + Game RTP + 新手體驗 RTP
```

- 轉製遊戲**不拆 Bonus Game RTP**；試算表「轉製遊戲」欄的 Bonus／Game 為同一合併欄位，原機的 Bonus／Feature 派彩全部歸入 Game RTP。
- 老手救援 RTP 固定 `0.00%`（主流遊戲為 0.50%）：**Landbase 轉製遊戲不啟用老手救援**。
- Inrc（Increment，彩池增量）是押注中滾入 Link 彩池的比例，**不計入玩家 Total RTP**；能否「滾 Inrc」與能否「拉 Link」是兩件事，見第 3 節。
- 其餘口徑（RTP ＝ Total Win ÷ 實際 Total Bet、產品顯示可四捨五入但計算用完整精度、各 Bet Mode 分母用該模式實際成本）沿用 Omniplay 第 1.4.1 節。

### 2.2 NB／EB RTP 配置

| Player Profile | 押注層級 | 判定金額 | Link RTP | Game RTP | 新手體驗 RTP | 老手救援 RTP | Total RTP | Inrc |
|---|---|---:|---:|---:|---:|---:|---:|---|
| 新手 | 低注 | `< $2` | 0.00% | 95.15% | 2.00% | 0.00% | 97.15% | 不滾 |
| 新手 | 高注 | `>= $2` | 0.00% | 95.15% | 2.00% | 0.00% | 97.15% | 滾 0.85% |
| 老手 | 低注 | `< $2` | 0.00% | 96.50% | 0.00% | 0.00% | 96.50% | 不滾 |
| 老手 | 高注 | `>= $2` | 2.00% | 94.50% | 0.00% | 0.00% | 96.50% | 滾 0.85% |

- 押注層級只分 **`< $2`／`>= $2` 兩級**，沒有 Omniplay 的小／中／大 Bet 三級與 `> $100` 門檻。
- 新手不論層級 Link RTP 皆為 0%；新手 `>= $2` 的 0.85% 只滾入彩池、不可中彩（第 4 節）。
- 老手 `>= $2` 的 Game RTP 比 `< $2` 低 2 個百分點，差額即 Link RTP，兩級 Total 相同。

### 2.3 BF／SF RTP 配置

| Player Profile | 押注層級 | 判定金額 | Link RTP | Game RTP | Total RTP |
|---|---|---:|---:|---:|---:|
| 新手 | 不分層級 | 全部 | 0.00% | （試算表為 0%，見第 7 節） | （待確認） |
| 老手 | 低注 | `< $2` | 0.00% | 96.50% | 96.50% |
| 老手 | 高注 | `>= $2` | 2.00% | 94.50% | 96.50% |

- BF／SF 的押注層級依 Omniplay 第 1.4.3 節，以 **Feature 購買價格 ÷ Feature Price 倍數反推的基礎押注**判定，不用購買總價。
- 試算表新手列的 BF／SF Total RTP 為 0%。新手若可購買 BF，其 Game RTP 待確認；但不論結果如何，**新手 BF 的 Link RTP 必為 0%**（第 4 節）。
- 老手 BF／SF 的 Game RTP 與 NB 相同層級一致（96.50%／94.50%），不是 Omniplay 的 92.50% 固定值。

### 2.4 與 Omniplay 主流配置的差異

| 項目 | Omniplay 主流 | Landbase 轉製 |
|---|---|---|
| RTP 拆分 | Link + Bonus Game + Game | Link + Game（Bonus 併入 Game） |
| 押注層級 | 小／中／大 Bet（`< $2`、`$2～$100`、`> $100`） | 低／高注（`< $2`、`>= $2`） |
| 新手 Total RTP（NB） | 95.00%（Bonus 2% + Game 93%）＋新手體驗 2% | 97.15%（Game 95.15% + 新手體驗 2%） |
| 老手 Total RTP | 96.50%（含老手救援 0.50%） | 96.50%（老手救援 0%） |
| 老手 BF／SF Game RTP | 92.50% 固定 | 與 NB 同層級相同（96.50%／94.50%） |
| 倍率權重套數（啟用 Card System 時） | 老手小／中／大三套 | 老手低／高注兩套（第 5.2 節） |

## 3. 系統機制

### 3.1 Link 彩金（Grand／Major）

Link 彩金為 Grand、Major 兩層累積彩池，參數依上線區域不同（試算表 `彩金參數` 頁，2026/05/14）：

| Area | Grand 起始彩池 | Major 起始彩池 | Grand RTP | Major RTP | Grand Inrc | Major Inrc | 備註 |
|---|---:|---:|---:|---:|---:|---:|---|
| Online（小平台） | $100,000 | $20,000 | 1.00% | 1.00% | 0.35% | 0.50% | |
| Online | $500,000 | $100,000 | 1.00% | 1.00% | 0.35% | 0.50% | |
| Okada | $1,000,000 | $100,000 | 1.30% | 0.70% | 0.20% | 0.20% | MFB 群組 |

- 第 2 節的 Link RTP 2.00% ＝ Grand 1.00% ＋ Major 1.00%（Okada 為 1.30% ＋ 0.70%）；Inrc 0.85% ＝ Grand 0.35% ＋ Major 0.50%（Okada 為 0.40%）。
- Link RTP 與 Inrc 由系統層依 Area 設定，數學模型不得把彩金參數寫死在輪帶或 Paytable；模型只負責 Game RTP 與新手體驗，並在 `Game Description` 記錄採用的 Area 參數版本。
- 「可滾 Inrc」表示該局押注會依 Inrc 比例滾入彩池；「可拉 Link」表示該局有資格中 Grand／Major。資格對照見第 2.2 節與第 4 節。
- 數學模型必須定義哪些派彩歸入 Link、哪些歸入 Game，不得重複計算。

### 3.2 新手體驗

- 新手體驗 RTP 2.00% 只給新手 Profile，老手為 0%；體驗內容與腳本依 Omniplay 的 [腳本規範.md](../腳本規範.md) 與 `System/機制說明書.md`。
- 新手體驗的派彩計入新手 Total RTP（97.15%），計算與驗證時必須與 Game RTP 分開統計。

### 3.3 老手救援

- Landbase 轉製遊戲**不啟用**老手救援，RTP 固定 0%；Config、Simulator 與 Demogame 不得出現老手救援的設定或演出。

## 4. 系統限制

| 限制 | 規則 |
|---|---|
| 新手標籤 | 玩家仍帶有新手標籤時，**任何 Bet Mode（含 BF／SF）都不得拉 Link 彩金**；不得因為購買 Feature 而繞過新手限制。 |
| 新手期 | 新手期不得拉彩金，Link RTP 必為 0%；`>= $2` 時只滾 Inrc、不中彩。 |
| 低注 | `bet_tier_amount < $2` 不得拉 Link 彩金，新手、老手皆同；NB／EB 以實際押注、BF／SF 以反推基礎押注判定。 |
| 系統最大賠付 | **單把派彩上限 `$10,000,000`**。數學模型必須驗算 `Max Multiplier × 該遊戲最大押注 ≤ $10,000,000`，超出者調低倍率上限或最大押注，並在數學文件明記。 |

- Link 資格一律由系統依 Profile 與 `bet_tier_amount` 判定；`link_enabled = false` 時不得只把派彩改成 0，結果中不得出現已觸發但不派彩的 Link 事件或演出（同 Omniplay 第 2.3.1 節）。
- 超過系統最大賠付時的處理方式（截斷或整把重骰）待確認（第 7 節）；確認前模型以「不可能超過」為設計目標，而非依賴截斷。
- Omniplay 第 1.4.5 節的 `$5,000,000`／`$1,000,000` 重骰上限**不適用**於 Landbase，以本節 `$10,000,000` 為準。

- 1.4.3 押注層級的 `bet_tier_amount` 計算方式（判定門檻改為本文件第 2.2 節的兩級）。
- 1.5 卡片倍率區間、1.5.1 區間工作表（欄位依第 5.2 節調整）。

- PARsheet。

### 5.2 Card System 的層級調整

啟用 Card System 時，Oldhand 的押注層級只有兩套：

```text
oldhand
├─ normal_bet    → low_bet／high_bet → weight_bg／weight_fg
├─ extra_bet     → low_bet／high_bet → weight_bg／weight_fg
├─ buy_feature   → low_bet／high_bet → weight_fg
└─ super_feature → low_bet／high_bet → weight_fg
```

- `low_bet` 對應 `< $2`，`high_bet` 對應 `>= $2`；不得保留 `medium_bet`／`big_bet` 的空殼設定。
- 區間工作表（`Multiplier_Weight`、`Avg_Multi`、`Nature_Prob`）的 Oldhand 欄位依低／高注命名，例如 `NB_BG_Low`／`NB_BG_High`；Newbie 欄位不變。
- 倍率上限依第 4 節系統最大賠付反推，不直接套用 Omniplay 第 1.4.4 節的 `20000x`／`2000x` 預設；Newbie 的 `30x`／`120x` 上限沿用。
- 是否啟用 Card System 隨第 1 節數學調性決定；未啟用時不得建立空白權重欄或 Card System 設定。

### 5.3 命名補充

- Landbase 轉製遊戲的 ParSheet ID 仍為 `H<三位數字>1`；同一數學供多個 Game ID 使用時（如 `H0111` → 102001／102002），數學模型只建一份，Game ID 對應記錄於 `Game Description` 工作表與 Game List。

## 6. 開發前檢查

- [ ] 已確認數學調性並記錄於 `Game Description`（原機為底或重新設計、目標 RTP、波動度、是否啟用 Card System）。
- [ ] RTP 配置採本文件第 2 節（Link + Game + 新手體驗），且與試算表「轉製遊戲」欄當前版本一致，已記錄引用日期。
- [ ] 押注層級只有 `< $2`／`>= $2` 兩級；Config、Simulator、Demogame 無小／中／大 Bet 殘留。
- [ ] 新手（含 BF／SF）與低注的 Link RTP 為 0%，且結果中無已觸發但不派彩的 Link 事件。
- [ ] 老手救援未啟用，Config 無相關設定。
- [ ] `Max Multiplier × 最大押注 ≤ $10,000,000` 已驗算並記錄。
- [ ] 採用的 Link 彩金 Area 參數版本已記錄；數學模型未寫死彩金參數。
- [ ] Omniplay 第 1.6 節其餘檢查項目全部通過。

## 7. 待討論事項

| 項目 | 現況 | 需決定 |
|---|---|---|
| 數學調性 | 無明確方向 | 以原機為底或重新設計；波動度／Hit Rate 目標；是否啟用 Card System |
| 新手 BF／SF RTP | 試算表為 0% | 新手是否可購買 BF／SF；可購買時的 Game RTP |
| 超過系統最大賠付的處理 | 只定上限 `$10,000,000` | 截斷或整把重骰；Simulator 與 Demogame 須一致 |
| 大注門檻 | 只有 `>= $2` 一級 | 押注選項極大的遊戲是否需要額外上限層級 |
