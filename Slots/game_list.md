> 遊戲名單來源：iGaming 遊戲代號一覽（Slot_Game-中辦 / Slot_Game-北辦）——**以此為準**
> 線上營運資料來源：`其他/Game List_Online.xlsx`（彩金版本、線數、最大獎金、RTP）
> 標準差來源：各遊戲 `Record/` 模擬報表的 `volatility_std`，**取 Normal Bet**；
> 　　同一版別取最新 math version、卡片系統 oldhand（長期玩家）那一輪。
> 　　RTP 未收斂的探測跑法（card_system=off、RTP 明顯超標）不採用。
> 　　標記「（未標版本）」者為代號一覽原有的單一標準差，來源未註明對應哪個 RTP 版本。

> **一款遊戲的列數 = max(RTP 版本數, Game List_Online 列數)。**
> 　　「RTP 版本」與「彩金版本」視為同一組版本的兩種寫法，按順序配對。
> 　　⚠ 配對順序尚待確認（92% ↔ 彩金版 / 94% ↔ 無彩金版），若相反需整份翻轉。
> 　　續列只留白 Game ID / ParSheet ID / 遊戲英文名稱 / 遊戲中文名稱，其餘欄位照填。

> 未收錄：Omnichannel（11xxxx，現場彩金版）、Game ID 100001~100010、109xxx、名稱仍為括號的未定名遊戲。
> 「彩金版本」以後的欄位空白＝該遊戲尚未在 Game List_Online 名單內。
> 押注欄只列有數值的模式；不適用或代號一覽未填者略過（北辦分頁本身無押注欄位）。
