## §2. 盤面結構（沿用 H026）

```text
   R1   R2   R3   R4   R5
┌────┬────┬────┬────┬────┐
│    │    │    │    │    │  Row 1
├────┼────┼────┼────┼────┤
│    │    │    │    │    │  Row 2
├────┼────┼────┼────┼────┤
│    │    │    │    │    │  Row 3
└────┴────┴────┴────┴────┘
```

**Reel / Row**

| Reel | Row 數 | 位置索引 |
| --- | --- | --- |
| R1 ～ R5 | 各 3 | Row 1～3（上到下） |

**得分方向**

- 固定 20 條賠線（線型同 H026），由最左輪（R1）起算、相鄰輪連續 3 個以上相同符號（含 Wild 替代）即中獎。
- 每條線只支付最高獎項；同一段可同時有多條線中獎，各自計分後加總。
- 單段得分 =（該段所有中獎線賠率加總 × Bet）×（當下全盤倍數框總和；沒有任何倍數框時以 x1 計），見 §5.4。

**補牌流程**

- 中獎符號消除後留下空位，同一輪上方符號往下掉落補位，空缺由上方補入新符號（不跨輪）。
- 得分的金色符號不消除，原位轉為 Wild（§5.3），不視為空格。
- 補位完成後重新判獎，直到沒有新的中獎線為止。

## §3. 符號類別

### 3.1 一般符號

| 代號 | 符號 |
| --- | --- |
| M1 | 骷髏 |
| M2 | 墨西哥帽 |
| M3 | 沙鈴 |
| M4 | 墨西哥夾餅 |
| M5 | 辣椒 |
| A | A |
| K | K |
| Q | Q |
| J | J |

- 出現位置：全盤面。
- A／K／Q／J 賠率相同。

### 3.2 特殊符號

| 代號 | 符號 |
| --- | --- |
| C1 | 彩罐（Scatter） |
| WW | Wild |
| G1～G5、GA、GK、GQ、GJ | 金色符號（M1～M5、A、K、Q、J 的金色版） |

- **C1**：可出現在 5 輪任意位置；不參與賠線；連消結束後最終盤面 3 個以上觸發 FG；無直接派彩。同一輪已有 1 個 C1 時，該輪後續補牌不再補入 C1（沿用 H026）。
- **WW**：替代所有一般符號與金色符號，不替代 C1；不自然出現，只由得分的金色符號轉換而來（§5.3）；本身不賠付。
- **金色符號**：照原符號判獎與計分（G1＝M1 …）；出現在 R1～R5 全部輪；出現率為平均每次停輪盤面（15 格）約 2 顆（輪帶與掉落的金色占比各 13%；為把 Demo RTP 壓在 500% 內，由原訂 2.5 顆調降）；停駐與得分時更新所在格的倍數框（§5.2、§5.3）。

### 3.3 倍數框（格子狀態）

- 倍數框是**盤面格子的狀態**，不是符號；符號消除、掉落時倍數框留在原格不動。
- 每格倍數框依層數對應倍數：1 層 x1、2 層 x2、3 層 x4、4 層 x8 … 11 層 x1024（每多 1 層倍數 ×2，上限 x1024）。

- WW 與 C1 無直接派彩。

## §5. 核心特色

### 5.1 Cascade 消除（沿用 H026）

- 中獎線上的符號消除、上方符號掉落補位，重新判獎直到沒有新的中獎線。

### 5.2 金色符號停駐：產生框或疊 1 層

- 金色符號每次**停駐**在盤面某格（開局停輪、連消補位掉落停住），就更新該格倍數框：
  - 該格**沒有**倍數框 → 產生 **x1** 倍數框。
  - 該格**已有**倍數框 → 疊 1 層（x1 → x2 → x4 → … → x1024）。
- 已達 x1024 → 維持 x1024。
- 只看最終停住的格子，掉落途中經過的格子不算。
- 一般符號停在有框的格子不改變倍數框。

### 5.3 金色符號得分：轉 Wild，並產生框或再疊 1 層

- 金色符號參與中獎時，該段消除後**原位轉為 WW**，不掉落、不視為空格。
- 轉 WW 的同時更新該格倍數框：
  - 該格**沒有**倍數框 → 產生 **x1** 倍數框。
  - 該格**已有**倍數框 → 再疊 1 層。
- 轉成的 WW 留在原位，下一段可替代一般符號參與中獎；WW 參與中獎後照一般符號消除，不影響倍數框。
- 未參與中獎的金色符號不轉換，照一般符號留在原位或隨補位掉落；掉落停住的新格依 §5.2 處理。

### 5.4 全盤倍數框計分（本作主特色）

- **每一段判獎算完該段總分後，乘上當下全盤所有倍數框的倍數總和**；盤面沒有任何倍數框時以 x1 計。
- 倍數框總和的計算時點：本段判獎前（已含本段停駐疊層，§5.2）；本段得分轉 WW 產生或疊加的框（§5.3）從**下一段**開始計入。
- 範例（BG）：
  1. 開局 R2 Row 2 停一個金色辣椒 → 該格產生 x1 框（全盤和 1）。第 1 段辣椒線中獎 0.25x × 1 → 得分 0.25x；金色辣椒轉 WW，R2 Row 2 疊成 x2（全盤和 2）。
  2. 第 2 段 WW 參與 A 線中獎 0.1x × 2 → 得分 0.2x；WW 消除，補位時一個金色 K 停在 R2 Row 2 → 該格疊成 x4（全盤和 4）。
  3. 第 3 段金色 K 參與 K 線中獎 0.5x × 4 → 得分 2x；金色 K 轉 WW，R2 Row 2 再疊成 x8（全盤和 8），下一段起計入。
- 單格上限 x1024；全盤 15 格的總和上限為 15,360。

### 5.5 倍數框保留與清除

- **Base Game**：每次 Spin 開始時清空全盤倍數框；同一次 Spin 的連消期間持續保留、疊加。
- **Free Game**：倍數框整段 FG 保留，每局延續上一局的倍數框，直到 FG 結束才清空。

## §6. 免費遊戲（Free Spins / Free Game, FG）

### 6.1 觸發

- 本次 Spin 連消結束後，最終盤面出現 3／4／5 個 C1，觸發 12／14／16 局 FG（沿用 H026）。

### 6.2 FG 玩法

- 規則同 Base Game（§5），差別只在倍數框整段 FG 保留不清空（§5.5）。
- FG 總局數上限 50 局（含 Retrigger，沿用 H026）。

### 6.3 Retrigger

- FG 單局連消結束後最終盤面 3／4／5 個 C1，再加 12／14／16 局；受 50 局上限限制。

## §7. 核心遊戲流程（Base Game）

1. 玩家選擇押注並按 Spin；清空全盤倍數框。
2. 5 輪 × 3 列停輪；每個金色符號停駐的格子產生 x1 框或疊 1 層（§5.2）。
3. 依 20 條線判獎；若有中獎，算出本段所有中獎線賠率加總 × Bet，再乘全盤倍數框總和（§5.4），累加到本次 Spin 總分。
4. 中獎的一般符號與 WW 消除；中獎的金色符號原位轉為 WW，該格產生 x1 框或疊 1 層（§5.3）。
5. 同輪上方符號掉落補位、空格由上方補入新符號；掉落停住的金色符號，該格產生 x1 框或疊 1 層（§5.2）。
6. 重複 3～5，直到沒有新的中獎線。
7. 依最終盤面 C1 數量判定是否觸發 FG（§6.1）。

---

## §8. 押注模式

### 8.1 Extra Bet

- 不提供。

### 8.2 Buy Feature

- 支付 75x Bet，先進行一局 BF 進場 Spin（最終盤面保證 3 個以上 C1），再依 12／14／16 局進入 FG（沿用 H026）。
- 進場 Spin 的得分保留，與 FG 總分合計。

## §9. 邊界 / 例外情境（Edge Cases）

### 9.1 倍數框

- **9.1.1 單格上限**：已達 x1024 的格子再停駐或轉 WW，維持 x1024。
- **9.1.2 無框計分**：全盤沒有任何倍數框時，得分以 x1 計。
- **9.1.3 框不隨符號移動**：倍數框屬於格子；該格符號消除或掉落都不帶走倍數框。
- **9.1.4 一般符號與 WW 不影響框**：只有金色符號的停駐與得分轉 WW 會改變倍數框。
- **9.1.5 沒移動不重算**：金色符號留在原位（沒掉落）時不算再次停駐，不會重複疊層。
- **9.1.6 同一顆金色符號可疊多次**：停駐疊 1 層、得分轉 WW 再疊 1 層；沒得分而隨補位掉到新格時，新格也疊 1 層。

### 9.2 金色符號與 Wild

- **9.2.1 只有得分的金色符號會轉 WW**。
- **9.2.2 轉 WW 時該格產生框或疊層**，本段得分不吃這次變化，從下一段起計入。
- **9.2.3 WW 不替代 C1**。

### 9.3 Scatter

- **9.3.1 FG 觸發判定時點**：本次 Spin 連消結束後，依最終盤面 C1 數量判定。
- **9.3.2 補牌限制**：同一輪已有 1 個 C1，該輪後續補牌不再補入 C1。

### 9.4 Free Game

- **9.4.1 倍數框整段保留**：FG 每局開始不清空倍數框，整段 FG 結束才清空。
- **9.4.2 局數上限**：含 Retrigger 最多 50 局。
