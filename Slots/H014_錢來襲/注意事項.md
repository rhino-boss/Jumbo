# H014 錢來襲 — 注意事項

本遊戲的特別操作與已知例外。改模型、改權重或交接前必讀。

## 1. 已知例外

### 1.1 自然機率 < 0.05% 的盤面 × R4 組合，卡片開啟時不會出現（2026-10-13，4.1.0.0）

- 規則：數學模型規範 §2.7（畫面看得到的組合都要有機會出現）與 §1.5（自然機率 < 0.05% 的區間不得給權重）衝突時，以 §1.5 為準。
- 下列組合自然會出現，但所在倍率區間在所有子表的自然機率都 < 0.05%，卡片區間權重為 0，Card-On 下不會出現：

| 押注 | 組合（數字分 × R4） | 倍率 | 區間 | 最高自然機率 |
|---|---|---|---|---|
| NB Bet10 | 1000 × 10X | 1,000x | (950, 1000] | 0.046%（B 表） |
| NB Bet50 | 10000 × 2X | 400x | (350, 400] | 0.03%（B 表） |
| NB Bet100 | 151 × 2X、155 × 2X | 3.02x、3.1x | (3, 4] | 0.03% |
| NB Bet100 | 50000 × 10X、100000 × 5X | 5,000x | (4000, 5000] | 0.03%（B 表） |

- 使用者同意暫不處理（2026-10-13）。若要消除，只能改 R4 權重讓這些組合自然也不出現。

### 1.2 RESPIN 重轉盤不會出現 0 分盤

- Description 4c：重轉後分數為 0 時重骰，所以「空 空 空」「空 0 空」「空 00 00」等 0 分重轉盤不會出現。屬規則，非權重問題。

### 1.3 Extra Bet 的 R4 輪帶空白格不會停在中線

- EB 規則「R4 移除空白」以空白權重 0 實現，輪帶上的空白是符號間的間隔格，捲動與上下半格看得到、中線停不到。1.0.0.2 原版即如此，未改。

## 2. 特別做法

- **Bet100 數字分上限**：4.0.0.0 起由 30000（300 倍）改為 500000（5000 倍），兩份 Help 都沒有此限制；最大數字分 101010 不會觸發。
- **Extra Bet 卡片**：以 Normal Bet 卡片為基礎，各得分區間權重 × (1 + k × Normal Bet 該區間 R4 有東西的比例)，k 使 RTP（÷1.5）＝92.0000%；輪帶權重沿用 1.0.0.2。
- **補合格區間**：自然機率 ≥ 0.05% 的區間都要有權重；補上的權重彼此比例照自然機率（取自然機率最高的子表），最小 1 ppm。
- **畫面組合檢查**：改卡片後除了 §2.7 的元素檢查，還要確認「各輪看得到的符號組合（R1～R3）」與「得分盤面 × R4 符號」在 Card-On 下都出現得了；區間指定的子表若缺組合，改用含該組合的子表。
- **模擬**：一律在模擬機 192.168.139.10（`ssh sim`，`/root/Simulator/H014_錢來襲/`）跑。
- **交付 SPS**：只交 `config.js`、`config_92A.js`、`Simulator.py`；差異說明見 `文件/SPS改版說明_5.0.0.0.md`。
- **不送驗**：H014 不需要送驗，只出內部 PARsheet（`文件/PARsheet/`），不做送驗版文件包（`文件/101002/`）。（2026-10-16 使用者確認）
