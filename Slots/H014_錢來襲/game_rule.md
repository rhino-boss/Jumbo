## §2. 盤面結構

### 2.1 盤面示意

```text
        R1     R2     R3   │  R4（特色轉輪）
      ┌─────┬─────┬─────┐ ┌─────┐
上    │     │     │     │ │     │
      ├─────┼─────┼─────┤ ├─────┤
中線  │  1  │  0  │  5  │ │ 2X  │   ← 唯一判獎線
      ├─────┼─────┼─────┤ ├─────┤
下    │     │     │     │ │     │
      └─────┴─────┴─────┘ └─────┘
        數字轉輪 → 組成「105」      特色 → 105 × 2
```

### 2.2 Reel／Row

| Reel | 可視 Row | 判獎 Row | 用途 |
| --- | ---: | --- | --- |
| R1 | 3 | 中線 | 數字轉輪 |
| R2 | 3 | 中線 | 數字轉輪 |
| R3 | 3 | 中線 | 數字轉輪 |
| R4 | 3 | 中線 | 特色轉輪 |

### 2.3 得分方向

- 只判中線 1 條。
- R1→R2→R3 中線符號由左至右串接成一個數字，空白（E）不佔位、直接略過。
- 串接後的數值即為「數字分」，單位為 Coin；換成 × bet 為 `數字分 ÷ 押注 Coin 數`。
- R4 不參與數字組合，只依中線符號給予特色效果（§5）。

### 2.4 補牌流程

不適用（無消除、無補牌）。

## §3. 符號類別

### 3.1 一般符號

| 代號 | 符號 |
| --- | --- |
| 10 | 數字 10 |
| 5 | 數字 5 |
| 1 | 數字 1 |
| 00 | 數字 00 |
| 0 | 數字 0 |
| E | 空白 |

- **R1**：10、5、1、E。
- **R2**：0、1、5、E；Bet50 以上加入 10、00。
- **R3**：0、1、5、E；Bet100 加入 10、00。Bet1 時 R3 固定停在 E，實際只有 R1、R2 兩輪組成數字。
- **E**：不組成數字，串接時略過。

### 3.2 特殊符號（R4 特色轉輪）

| 代號 | 符號 |
| --- | --- |
| 2X | 2 倍 |
| 5X | 5 倍 |
| 10X | 10 倍 |
| RESPIN | 重轉 |
| C1 | 綠 BONUS |
| C2 | 紅 BONUS |
| E | 空白 |

- 只出現於 R4。
- **2X／5X／10X**：數字分乘上該倍數；數字分為 0 時無效果。
- **RESPIN**：R1～R3 免費重轉一次（§5.2）。
- **C1／C2**：進入幸運轉盤（§5.3）；C1 用綠轉盤、C2 用紅轉盤。
- **E**：無效果。

各押注 R4 可出現的符號：

## §4. 賠率表（Pay Table）

本作無固定賠率表，數字分由中線組合直接決定。下列為各押注可能出現的全部數字分（Coin）。

**Bet1**（R3 固定為 E，只有 R1、R2 兩輪；共 16 組合、12 種數字分）：0、1、5、10、11、15、50、51、55、100、101、105

**Bet5／Bet10**（R1：10、5、1、E；R2／R3：0、1、5、E；共 64 組合、36 種數字分）

| R1 | 數字分 |
| --- | --- |
| E | 0、1、5、10、11、15、50、51、55 |
| 1 | 100、101、105、110、111、115、150、151、155 |
| 5 | 500、501、505、510、511、515、550、551、555 |
| 10 | 1000、1001、1005、1010、1011、1015、1050、1051、1055 |

**Bet50**（R2 加入 10、00；共 96 組合、51 種數字分）：Bet5／Bet10 的 36 種，另加 15 種：

| R1 | 新增數字分 |
| --- | --- |
| 1 | 1100、1101、1105 |
| 5 | 5000、5001、5005、5100、5101、5105 |
| 10 | 10000、10001、10005、10100、10101、10105 |

**Bet100**（R2、R3 皆加入 10、00；共 144 組合）：數字分上限 30000，超過即重轉（§9.2），實際可出現 64 種，即 Bet50 的 51 種另加 13 種：

1110、1500、1510、5010、5110、5500、5510、10010、10110、10500、10510、11000、11010

- Bet100 因上限排除的數字分：50000、50010、51000、51010、100000、100010、101000、101010。
- 派彩口徑：`數字分 × R4 倍數`，單位 Coin；× bet = 派彩 ÷ 押注 Coin 數。
- 幸運轉盤獎項另計，派彩 = 獎項 × 押注（§5.3）。

## §5. 核心特色

### 5.1 特色轉輪倍數（2X／5X／10X）

- R4 中線為 2X／5X／10X 時，數字分 × 倍數。
- 數字分為 0 時，倍數不產生派彩。

### 5.2 重轉（RESPIN）

1. R4 中線為 RESPIN 時，R1～R3 免費重轉一次，R4 不重轉。
2. 該局派彩 = 重轉前數字分 ＋ 重轉後數字分。
3. 重轉前後數字分合計必須 ≥ 1 × bet；不足時重轉結果重抽至符合。
4. 重轉後數字分為 0 時，重抽至大於 0。
5. 重轉後數字分小於重轉前時，兩者互換，先演出較小的分數。
6. Bet100：重轉前、重轉後數字分各自不得大於 30000（300 × bet），超過則重抽。
7. Bet100 重轉時 R3 為 10 或 00，依 switch 權重決定 R2、R3 符號是否互換。

### 5.3 幸運轉盤（Lucky Wheel）

- R4 中線為 C1／C2 時進入幸運轉盤，必定得獎。
- 轉盤 8 格，依權重抽出一格；獎項為押注倍數，派彩 = 獎項 × 押注（例：Bet5 抽中 200 → 1000 Coin）。

| 轉盤 | 押注 | 獎項（× 押注） |
| --- | --- | --- |
| 綠轉盤（C1） | Bet5、Bet10 | 5、10、15、20、30、50、100、200 |
| 紅轉盤（C2） | Bet50、Bet100 | 10、20、30、50、100、200、500、1000 |

- 該局派彩 = 數字分 + 獎項 × 押注，轉盤獎項不乘 R4 倍數。

### 5.4 卡片系統與表選擇

- R1～R3 使用權重輪帶，每個押注有 A／B（Bet100 另有 C）多張表，依卡片系統權重選表。
- R4 權重依 R1～R3 數字分分組（0、1、5、10、11、15、50、51、55、100～3000、3001～6000、>6000）。
- 幸運轉盤權重依所選表決定。

### 5.5 OP Jackpot

- 由 R4 的 RESPIN、C1 或 C2 隨機觸發。
- 畫面出現 12 枚錢幣，內含 GRAND、MAJOR、MINOR、MINI；每次選 1 枚揭示。
- 先集滿 3 個相同彩金符號，即獲得該彩金並結算。
- GRAND、MAJOR 為連機累進彩金，投注選項 2.00 以上解鎖。
- MINOR、MINI 為紅利彩金，依投注選項改變。
- 投注越高，觸發機率越高。

## §7. 核心遊戲流程（Base Game）

1. 玩家選擇押注與押注模式，扣除押注金額。
2. 依卡片系統選表，R1～R3 停輪，計算數字分。
3. 依數字分分組選 R4 權重，R4 停輪。
4. 依 R4 結果處理：
   - 2X／5X／10X：數字分 × 倍數。
   - RESPIN：執行 §5.2。
   - C1／C2：數字分照計，再進入 §5.3 幸運轉盤。
   - E：只計數字分。
5. RESPIN／C1／C2 時判定是否觸發 OP Jackpot（§5.5）。
6. 結算本局派彩。

## §8. 押注模式

### 8.1 Extra Bet

- 押注金額為 Normal Bet 的 1.5 倍（額外支付 50%）。
- R4 移除空白（E），每局必定出現特色。
- 其餘規則、轉盤、押注解鎖內容與 Normal Bet 相同；使用 H014192A_Extra 模型。

### 8.2 Buy Feature（購買特色）

不提供。

## §9. 邊界 / 例外情境（Edge Cases）

### 9.1 數字組合

- R1～R3 全為 E：數字分 0。
- 數字分 0 且 R4 為倍數：派彩 0。
- 前導 0／00（例 E 00 5）：數字分為 5。

### 9.2 重抽與保底

- Bet100 R1～R3 數字分 > 30000 時重轉。
- 重抽超過 10 次，改用該狀況的固定組合（模型「重轉超過」表）。

### 9.3 演出規則（不影響派彩）

- 數字分為 0 時，R2、R3 停在 0 的位置，依「0換E」權重可能往下跳一格，改顯示 E。
- 有贏分且 R1 不為 0／E 時，R1 依假表演權重決定是否觸發假表演與方向；R4 不為 E 時同理。
- 各押注初始盤面使用固定 RNG：

| 押注 | R1 | R2 | R3 | R4 |
| --- | ---: | ---: | ---: | ---: |
| Bet1 | 1 | 0 | 2 | 3 |
| Bet5 | 3 | 2 | 4 | 5 |
| Bet10 | 3 | 4 | 0 | 7 |
| Bet50 | 3 | 8 | 0 | 5 |
| Bet100 | 1 | 8 | 8 | 7 |

### 9.4 斷線

- 特色遊戲期間斷線，系統自動完成並將派彩加入餘額。
