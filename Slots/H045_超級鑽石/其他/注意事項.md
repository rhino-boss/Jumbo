# H045 超級鑽石 — 注意事項

本遊戲的特別操作與已知例外。改模型、改權重或交接前必讀。

## 1. 來源

- 非競品衍生：初始來源為自家 H0161（幸運王牌）與前端規格書 Lucky Ace Deluxe v2.2.0（`Source/H0451.xlsx` Game Description）。
- 版本號只記在 `Source/version.txt`（一行、所有模型共用），工作簿 Overview 不寫版本；`config.js` 的 `excel_version` 只填第 1 碼（6），各 RTP config 填完整版本（2026-11-02）。
- 已知例外：Overview B2 Model 名稱 `H045192` 等未帶 A／B 後綴，math-model-checker 會報 MISMATCH，尚未修正（待使用者決定）。

## 2. 特別做法

- **金框**：金框是旗標不是符號。各 Symbol 表可用 config 的 `gold_count_weight` 覆蓋場景預設（Simulator `gold_key`、Demo `goldCountFor`）。
- **BF 進場盤（BF_Symbol）**：直接複製 H016 幸運王牌的 BF 表（G 符號 ID 11～18 減 8 對應基本符號），設計保證任何停點都不得分、C1 至少 3 顆（窮舉 15,360,000 盤 0 中獎）；進場盤照常判獎、照常出金框（金框權重同 BG 表／Parameter BG），程式在得分時直接報錯（6.0.1.2，2026-11-02）。**BF 表必須由表本身保證不得分，不可靠程式跳過判獎。**
- **大鬼分裂**：分裂出來的一律是 W2（6.0.1.1）。
- **SCR**：OP Jackpot 依 SPS 101015 scatterComboRate 填，A／B 分版、新手獨立、92 與 Bet100 用老手 92、94 用 94% 列（6.0.1.0）。
- **押注分層**：小 Bet（實際押注 < $2）用 94 版，大 Bet（基礎押注 > $100）用 Bet100（對齊 SPS isHighBet()），其餘用 92 版。
- **Demo 專用**：`config_120A_Demo.js`／`Source/H0451120_Demo.xlsx` 只給 Demo 用，不交 SPS、不出 PARsheet 送驗。
- **A／B 版**：B 版比 A 版深（老手 FG、BF），BG 與新手同 A 版；上線效果見 `其他/上線觀察.md`。
