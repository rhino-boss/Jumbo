八、調整方式與資料來源

  1. 目標確認：大 Bet（>$100）FG cap 2,000x、92A/88B 兩版、最高權重區間留 (1000, 2000]、bet_multi 用 OP 真實檔位 150、SCR 沿用 NB（使用者 2026-09-08 確認）。
  2. 歸零：(2000, 3000] 與 (9000, 10000] 權重設 0（88B 的 (2000, 3000] 原本即 0）。
  3. 補償求解：主體（20~200x]）係數 a、尾端（200~2,000x]）係數 b 兩未知數， 解「Σw = 10⁹」與「Σ L·E 不變」兩條線性約束；92A a=0.99839887、b=1.18877641；88B a=0.99931427、b=1.05130704。
  4. 整數化：最大餘數法補足總和，低倍相鄰區間逐單位搬移，殘差壓到 < 1e-9。
  5. 寫檔：config 新增 weight_fg_big → XLSX Multiplier_Weight 以 XML 手術加靜態欄 Weight_NB_FG_Big（G 欄）→ openpyxl 讀回逐格比對 0 差異。轉檔工具已依規範移除，由 AI 直接轉換。
  6. 程式：Simulator 新增 CARD_PROFILE_OLDHAND_FG_BIG（老手 NB＋>$100 自動改抽）；index profileFgCards 同步；config 無 big 欄時退回一般卡組。
  7. 版本：3.3.2.0 → 3.4.0.0（只改倍率權重：第二碼 +1）；封存 Versions/3.4.0.0、manifest 更新、PARsheet 五份重產。
