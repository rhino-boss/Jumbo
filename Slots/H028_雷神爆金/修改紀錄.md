## 2026-09-08：Simulator 加入 OP Jackpot 彩金模擬

- 新增批次／環境參數：`jackpot_file`（A／B／C，對應 `Slots/OP Jackpot/JP0100A/B/C.xlsm`；空值＝關閉）與 `jackpot_option`（Parameter_List 的 Option：28=SPS use、1=Lakiwin、2=Filbet）；BATCH_RUNS 可逐批指定，env 為 `H028_JACKPOT_FILE`／`H028_JACKPOT_OPTION`。
- 觸發模型（依 2026-09-08 確認的機制）：每個出現 ≥1 SC 的 Spin（BG＋每次 Free Spin；BF 進場畫面計 1）判定一次；真實觸發率由各獎項固定 RTP 反推（`startup% = RTP% − Increment%`；JP1/JP2 除以池底、JP3/JP4 除以固定倍數 x），再除以該組合的 SCR（取自 RTP 工作簿 OP Jackpot 頁，依 NB／NB_Newbie／BF 選欄）放大成條件機率；查表 bet 檔以實際押注對應（NB＝bet_multi、BF＝75×bet_multi），找不到檔位即報錯停止，不內插。
- 派彩模型：JP1/JP2 連機累進——每局將 Increment%×押注 進池（各執行緒獨立池），命中派「池底＋累積」後歸零；JP3/JP4 固定 x×實際押注。彩金派彩不入 `rtp_game`，另計 `rtp_link`（JP1+JP2）與 `rtp_bonus_game`（JP3+JP4），`rtp_total = game + link + bonus`（報表檔名 RTP tag 同步採含彩金總值）。
- Overview／Console 新增：`jackpot`、`link_enabled`（依所選檔案是否可派 JP1/JP2）、`rtp_link`／`rtp_bonus_game`（含設定值註記）、By Game 的 `jp1~4_hits`（含週期與派彩）、`jp_trigger_p_cond`、`jp_scr_used`、`jp_contribution_rate`、`jp_pool_note`。
- 已知口徑：JP1/JP2 池為各 worker thread 獨立（RTP 正確、池金額分布較真池小）；短場次 Link 實測趨近 0 屬正常（週期 10⁸ 級），以設定值註記對照；A 組玩家不可中 JP1/JP2 但仍貢獻 Increment（jp_contribution_rate ≈ 0.85%）。
- 彩金關閉時不產生任何額外 RNG 抽樣，與既有結果路徑一致。
