## §2. 盤面結構

```text
         R1   R2   R3   R4   R5   R6
         ↓    ↓    ↓    ↓    ↓    ↓
      ┌────┬────┬────┬────┬────┬────┐
      │    │    │    │    │    │    │
      ├────┼────┼────┼────┼────┼────┤
      │    │    │    │    │    │    │
      ├────┼────┼────┼────┼────┼────┤
      │    │    │    │    │    │    │
           ├────┼────┼────┼────┤
           │    │    │    │    │
                ├────┼────┤
                │    │    │
```

**Reel / Row**

| Reel | Row 數 | 說明 |
| --- | --- | --- |
| R1 | 3 | 有效記分區 |
| R2 | 4 | 有效記分區 |
| R3 | 5 | 有效記分區 |
| R4 | 5 | 有效記分區 |
| R5 | 4 | 有效記分區 |
| R6 | 3 | 有效記分區 |

**得分方向**

- 由最左輪 R1 起算，往右相鄰輪盤連續出現相同符號（或 Wild），達 3 輪以上成立。
- 連續中斷即不成立；不使用固定線。
- Ways 數固定上限 `3 × 4 × 5 × 5 × 4 × 3 = 3,600`。
- 單組得分 = 符號賠率 × Ways 數 × 當前乘數階級對應倍數。

**補牌流程**

- 參與中獎的普通符號消除後，依當把選定的掉落表補入新符號（不沿用原輪帶）。
- 參與中獎的金框符號不補新符號，原位轉成 Wild（見 §5.1）。
- 補牌完成後重新判獎，直到沒有新中獎為止。
- 掉落表 A / B / C 於每把 Spin 開始時抽定，整把沿用；前 3 次連消與第 4 次之後使用不同掉落權重段位。

## §3. 符號類別

### 3.1 一般符號

| 代號 | 符號 |
| --- | --- |
| M1 | 高分符號第 1 名 ⏳（主題美術未定） |
| M2 | 高分符號第 2 名 ⏳ |
| M3 | 高分符號第 3 名 ⏳ |
| M4 | 高分符號第 4 名 ⏳ |
| A | 低分符號第 1 名 |
| K | 低分符號第 2 名 |
| Q | 低分符號第 3 名 |
| J | 低分符號第 4 名 |

- 出現位置：R1 ~ R6 全盤面。
- `G1 ~ G4`、`GA ~ GJ` 為上述一般符號的金框版本，判獎時先還原成對應一般符號（見 §3.3）。

### 3.2 特殊符號

| 代號 | 符號 |
| --- | --- |
| C1 | Scatter |
| WW | Wild |

- **C1**：6 輪皆可出現；不參與 Ways 計算；整把連消全部結束後統計總數，≥3 觸發 FG；無直接派彩。
- **WW**：替代所有一般符號，不替代 C1；不存在於初始輪帶與掉落表，僅由中獎金框轉化而成。
- 本作**無炸彈機制**：H015 的「每段 Cascade 抽炸彈階數」整組移除，乘數推進改由消除次數與倍數金框驅動（見 §5.2、§5.3）。

### 3.3 金框符號（Gold Symbol）與倍數標記

金框是**一般符號的附加狀態**，不是獨立符號。

- 只出現在 R3、R4。
- 判獎時視為其對應的一般符號參與 Ways 計算。
- 金框分兩種：**一般金框**（無倍數標記）與**倍數金框**（附帶一個倍數標記，值取自乘數階梯的階級值，見 §5.2）。
- **盤面同一時間僅存在 1 顆倍數金框**：盤面上沒有倍數金框時，從現有金框中隨機挑 1 顆賦予倍數標記；已有 1 顆時，新生成的金框一律為一般金框。
- 倍數標記的值域與權重：BG ⏳、FG ⏳（FG 分布應高於 BG）。

| --- | --- | --- | --- | --- |
| M1 / G1 | 2.5 | 1.5 | 1.0 | 0.5 |
| M2 / G2 | 1.5 | 1.0 | 0.75 | 0.4 |
| M3 / G3 | 1.0 | 0.75 | 0.5 | 0.25 |
| M4 / G4 | 1.0 | 0.75 | 0.5 | 0.25 |

## §5. 核心特色

### 5.1 金框 → Wild（沿用 H015）

- 金框只出現在 R3、R4；判獎時視為對應一般符號。
- 實際參與本段中獎的金框，結算後原位轉成 `WW / Wild`，留在盤面參與後續 Cascade。
- 未參與中獎的金框不轉換。
- 金框轉成 Wild 後，不再保留金框屬性與倍數標記。

### 5.2 乘數階梯（Cascade Multiplier）

- 乘數階梯：`x1`、`x2`、`x4`、`x8`、`x16`、`x32`、`x64`、`x128`、`x256`、`x512`、`x1024`。
- BG 從 `x1` 階起算；FG 從 `x8` 階起算。
- **每完成一次有得分的消除，乘數階級向上推進 1 階**（沿用 H015 的消除推進；炸彈推進已移除）。
- 達最高階後維持，不再提升；新的一把 Spin 開始時重置回起始階。

### 5.3 倍數金框跳階（本作主特色）

- 每顆金框附帶倍數標記，值為乘數階梯上的某一階級值（例：`x4`、`x16`、`x64`）。
- **當帶倍數的金框參與中獎（被消除轉 Wild）時，當前累積乘數階級「直接跳到」該金框倍數對應的階級。**
- 跳階後即以新階級倍數結算**本段**贏分（跳階先於本段計分）。
- 同一段有多顆倍數金框參與中獎時，跳到其中**最高**的倍數階級。⏳ 待確認
- 金框倍數對應階級**低於**當前階級時不跳階（只升不降）。⏳ 待確認
- 跳階後，後續消除仍依 §5.2 繼續逐階推進（例：跳到 `x64` 後下一段為 `x128`）。

範例：

1. BG 第一段消除（當前 `x1`），一顆 `x16` 金框參與中獎 → 階級跳到 `x16`，本段贏分 × 16。
2. 該段結束，消除推進 +1 階 → 下一段起始為 `x32`。
3. 第二段若無倍數金框參與，得分即用 `x32`；結束後推進至 `x64`。

### 5.4 掉落表 A / B / C（沿用 H015）

- 每把 Spin 開始抽定 `A` / `B` / `C` 其中一套掉落表，整把沿用。
- 前 3 次連消與第 4 次之後使用不同掉落權重段位。

## §6. 免費遊戲（Free Spins / Free Game, FG）

### 6.1 觸發

- BG 所有 Cascade 結束後，最終盤面 `C1 >= 3` 觸發 FG。
- 初始場次：`10 + (Scatter 數量 - 3) × 2`。

### 6.2 FG 玩法

- FG 使用專用 table 權重與專用掉落權重。
- 乘數階級從 `x8` 階起算；每局 FG 開始時重置回 `x8`。⏳（是否改為整場 FG 不重置，待數值評估）
- 金框附帶倍數的值域與權重高於 BG。⏳ 具體分布待確認
- H015 的「FG 首消保底炸彈」機制隨炸彈移除；是否改為「指定場次保底 1 顆倍數金框」⏳ 待確認。
- 其餘金框轉 Wild、跳階、掉落規則與 BG 相同。

### 6.3 Retrigger（加局）

- FG 單局結束後最終盤面 `C1 >= 3` 即再加局，公式同初始觸發：`10 + (Scatter 數量 - 3) × 2`。
- 含 retrigger 在內，單次進入 FG 總場數上限 `50`。

## §7. 核心遊戲流程（Base Game）

1. 玩家設定 bet，按下 Spin；乘數階級設為 `x1`。
2. 系統依 BG table 權重抽出當局初始輪帶表，並抽定本把掉落表類型（A / B / C）。
3. 盤面生成，僅保留固定 24 格有效記分區。
4. R3、R4 的金框符號還原成對應一般符號參與判獎，保留金框位置與其倍數標記。
5. 由左至右進行 Ways 判獎；Wild 可替代一般符號。
6. 若有中獎：檢查本段參與中獎的倍數金框，依 §5.3 執行跳階（取最高、只升不降）。
7. 以跳階後的當前階級倍數結算本段贏分，累加到本局總得分。
8. 參與中獎的普通符號消除、依掉落表補入新符號；參與中獎的金框原位轉成 Wild。
9. 本段結束，乘數階級推進 1 階。
10. 回到步驟 5 重新判獎；若無新中獎則進入步驟 11。
11. 統計最終盤面 `C1` 數量；`>= 3` 觸發 FG（見 §6）。
12. 本次 Spin 結算派彩。

## §9. 邊界 / 例外情境（Edge Cases）

### 9.1 金框 / Wild 相關

- **9.1.1 金框只出現在 R3、R4**：其餘輪不自然生成金框。
- **9.1.2 金框未中獎不轉換**：未參與中獎的金框不轉 Wild、不觸發跳階。
- **9.1.3 Wild 不自然出現**：初始輪帶與掉落表皆無 Wild，僅由中獎金框轉換。
- **9.1.4 轉換後屬性消失**：金框轉成 Wild 後不再帶金框屬性與倍數標記。

### 9.2 倍數機制相關

- **9.2.1 跳階時機**：本段中獎確立後、本段計分前執行跳階；本段贏分用跳階後倍數。
- **9.2.2 只升不降**：金框倍數階級 ≤ 當前階級時不變動。⏳ 待確認
- **9.2.3 多顆取最高**：同段多顆倍數金框參與中獎時，只跳一次、取最高階。⏳ 待確認
- **9.2.4 跳階與推進疊加**：跳階後該段結束仍照常推進 1 階。
- **9.2.5 無炸彈**：本作不存在炸彈抽選；乘數變動只有「消除推進 +1 階」與「倍數金框跳階」兩種來源。
- **9.2.6 上限維持**：達 `x1024` 後維持，不再提升。

### 9.3 Scatter 相關

- **9.3.1 Scatter 可出現在 6 輪**。
- **9.3.2 Scatter 不參與 Ways、無直接派彩**。
- **9.3.3 Scatter 不參與消除**：留到整把結束後統計。
- **9.3.4 觸發判定點**：所有 Cascade 完成後才判定 FG 觸發。

### 9.4 Free Game 相關

- **9.4.1 FG 可 retrigger**，公式同初始觸發。
- **9.4.2 FG 總場數上限 50**（含 retrigger）。
- **9.4.3 FG 起始階級 x8**：每局起始重置規則見 §6.2 ⏳。

### 9.5 Buy Feature 相關

- **9.5.1 Buy 價格待定**：跳階機制影響 FG 期望值，沿用 75x 前必須先跑模擬驗證。
- **9.5.2 Buy 進入後沿用 FG 規則**。

### 9.6 Way Game 計算相關

- **9.6.1 Ways 由左至右連續計算**；某輪無該符號或 Wild 即中止。
- **9.6.2 Wild 替代不改變 Ways 算法**。
- **9.6.3 多符號同段中獎**：各自算 Ways 派彩後相加，再套用當段倍數。

### 9.7 連消（Cascade）相關

- **9.7.1 終止條件**：直到不再形成新中獎。
- **9.7.2 補位來源為掉落表**，不沿用原輪帶。
- **9.7.3 掉落表按連消深度切換**：前 3 次與第 4 次之後不同。
