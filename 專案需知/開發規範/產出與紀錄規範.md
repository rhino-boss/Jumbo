# 產出與紀錄規範

本文件定義每個 Slot 專案**必須產出的文件**與 `修改紀錄.md` 的格式。製作順序與各階段操作見[開發流程.md](../開發流程/開發流程.md)。

## 1. 必要產出文件

每個專案必須產出下列文件；任一項缺漏，專案不得視為完成交付：

| 產出 | 說明 | 依據規範 |
|---|---|---|
| `game_rule.md` | 遊戲規則正式來源 | [數學文件規範.md](Omniplay/數學文件規範.md) |
| `game_help_draft.md` → `{GameID}_Help.xlsx` | Help 先寫 Markdown 草稿再轉 xlsx，兩者內容一致 | [數學文件規範.md](Omniplay/數學文件規範.md) |
| `game_description.md` | 模型參數使用方式說明 | [數學文件規範.md](Omniplay/數學文件規範.md) |
| `H0xx1*.xlsx` → PARsheet | 數學模型為正式參數來源，另轉出對外提供的 PARsheet | [數學模型規範.md](Omniplay/數學模型規範.md)、[數學文件規範.md](Omniplay/數學文件規範.md) |
| `config.js`、`config_<RTP><Variant>.js` | Simulator 與 Demogame 共用的執行參數，由數學模型轉出 | [模擬程式規範.md](模擬程式規範.md) |
| `Simulator.py` | 模擬程式 | [模擬程式規範.md](模擬程式規範.md) |
| `index.html` | Demogame | [Demogame規範.md](Demogame規範.md) |
| `數值報告_<遊戲中文名>.md`＋`.html` | 本作與對標競品、前作的差異分析 | [數值報告規範](數值報告規範.md) |
| `修改紀錄.md` | 專案根目錄，依版本記錄數學調性的修改，格式見第 2 節 | 本文件 |
| `注意事項.md` | 本遊戲的特別操作與已知例外：偏離規範或預設的設定、經使用者同意暫不處理的檢查項、與其他遊戲不同的做法；每項註明日期、版本與原因，改模型、改權重或交接前必讀 | 本文件 |
| `{GameID}_Game Description.docx` | 依 Help 填寫，分完整版與送驗版 | [送驗文件規範.md](Omniplay/送驗文件規範.md) |
| `{GameID}_Math Document Description.md`＋`_EN.md` | 數學模型的工作表、參數、遊戲邏輯與卡片系統說明 | [送驗文件規範.md](Omniplay/送驗文件規範.md) |
| `文件/{GameID}_腳本規格.xlsx` | 挑腳本用的腳本表（2026-10-28 起統一此檔名） | [腳本規範.md](Omniplay/腳本規範.md) |

各檔案的存放位置見第 3 節。

- 上表「→」的轉換與 Config 一律由 AI 轉出，專案內不建立、不維護任何轉檔工具。
- 轉換結果必須可由來源重建；轉換錯誤時修正來源後重新轉出，不直接修補轉出結果。

## 2. 修改紀錄格式

`修改紀錄.md` 放在專案根目錄，**依版本分節、不以日期分節**：

- 每個四碼版本一節，標題寫 `## v<第 1 碼>（<四碼版本>）`，例如 `## v5（5.1.0.0）`、`## v5（5.0.0.0）`；由新到舊排列。
- 只改倍率權重（卡片權重，[數學模型規範 1.3](Omniplay/數學模型規範.md) 第 2 碼）時升成 `5.1.0.0` 這類版本，同樣**獨立成一節**，只列該版本內的修改；SCR（第 3 碼）、其他文件（第 4 碼）同理。
- 每節用編號清單，一項一件事，句尾以全形括號附日期 `（MM/DD）`。
- **只記錄跟數學調性有關的內容**：規則、賠率、輪帶、金框與倍數權重、卡片權重、RTP 拆分與週期、模擬驗證結果等。Demogame 介面、演出、文件、工具的修改不記在這裡（以 git commit 為準）。Demogame 的「版本紀錄」（`index.html` 的 `#change-log-wrap`）是本檔的複本，本檔更新時同步更新。
- 項目歸到**修改當時的目前版本**；**只記已完成的修改**，不寫進行中、待辦或「待重算」之類的狀態。
- 數學版本細節另見 `Versions/version_manifest.json`。
- 每次新增調性項目（數學模型或倍率權重調整）時，同步把 Demogame `index.html` 的 `window.DEMOGAME_LAST_TUNING` 改成當下的日期與時間 `YYYY-MM-DD HH:MM`（頁尾「最後調性更新」，見 [Demogame規範](Demogame規範.md) 第 5 節）。

範例：

```text
## v5（5.1.0.0）

1. 92A 卡片權重重解：BG Trigger Cap 350x → 300x。（10/20）
2. Card-On 驗證 Oldhand 92.03%、Newbie 92.98%、BF 92.51%。（10/20）

## v5（5.0.0.0）

1. 升 v5：啟用盤面表 2（高連消表），BG 選表 9 : 1、FG 2 : 8。（10/12）
2. 表 2 補牌權重集中、輪帶 M1～M4 約一半換成低倍符號。（10/12）
```

## 3. 專案目錄與存放位置

```text
Slots/H0xx_遊戲名稱/
├─ game_rule.md
├─ game_help_draft.md
├─ game_description.md
├─ 注意事項.md                 ← 本遊戲的特別操作與已知例外
├─ Simulator.py
├─ index.html
├─ config.js
├─ config_92A.js
├─ config_94A.js
├─ Source/
│  ├─ H0xx1.xlsx
│  ├─ H0xx192A.xlsx
│  ├─ H0xx194A.xlsx
├─ 文件/
│  ├─ <GameID>_Help.xlsx
│  ├─ <GameID>_Game Description.docx           ← 完整版（內容同 Help，不刪減）
│  ├─ <GameID>_Math Document Description.md
│  ├─ <GameID>_Math Document Description_EN.md
│  ├─ PARsheet/                 ← 專案的正式 PARsheet（主檔名加 R，底線後綴在 R 之後）
│  │  ├─ H0xx1R.xlsx
│  │  └─ H0xx19xR.xlsx
│  └─ <GameID>/                 ← 送驗文件包
│     ├─ <GameID>_Game Description.docx        ← 送驗版（移除送驗禁止項目）
│     ├─ PARsheet/             ← 數學模型送驗版（移除送驗禁止項目）
│     │  └─ H0xx19x.xlsx
│     └─ Simulator/
│        ├─ Simulator.py
│        └─ config_9x.js
├─ 其他/
│  ├─ 數值報告_<遊戲中文名>.md   ← 數值報告：與對標競品、前作的差異分析（見數值報告規範）
│  └─ 數值報告_<遊戲中文名>.html
├─ Record/
└─ Versions/
   ├─ version_manifest.js
   └─ version_manifest.json
```

- A／B、92／94、Buy／Super Feature 只依產品實際需求增減。
- 目錄中的檔名、版本及報表命名必須符合現行規格，不以舊遊戲的歷史命名為準。
- `Source/` 內不放任何轉檔腳本；Excel↔Config 轉換由 AI 執行。
- 數值報告（與競品、前作的數學差異分析）一律命名 `數值報告_<遊戲中文名>.md`＋`.html`（例：`數值報告_錢來襲.md`），放在專案 `其他/`；不再使用 `差異分析_<遊戲名稱>`、`競品比較_H0xx.md`、`競品差異分析_<競品名>.md` 等舊檔名。

| 存放位置 | 放什麼 | 製作方式見 |
|---|---|---|
| 專案根目錄 | `game_rule.md`、`game_help_draft.md`、`game_description.md`、`注意事項.md`、`config.js`、`config_<RTP><Variant>.js`、`Simulator.py`、`index.html` | 各檔對應規範（見第 1 節） |
| `Source/` | 數學模型 `H0xx1*.xlsx` | [數學模型規範.md](Omniplay/數學模型規範.md) |
| `文件/` | `{GameID}_Help.xlsx`、`{GameID}_Game Description.docx`（完整版）、`{GameID}_Math Document Description.md`＋`_EN.md` | [數學文件規範.md](Omniplay/數學文件規範.md)、[送驗文件規範.md](Omniplay/送驗文件規範.md) |
| `文件/PARsheet/` | PARsheet（主檔名加 `R`，底線後綴在 `R` 之後） | [數學文件規範.md](Omniplay/數學文件規範.md) PARsheet 節 |
| `文件/{GameID}/` | 送驗資料夾 | [送驗文件規範.md](Omniplay/送驗文件規範.md) 1.1 |
| `其他/` | `數值報告_<遊戲中文名>.md`＋`.html` | [數值報告規範](數值報告規範.md) |
| `Record/` | 模擬報表 `.xlsx` | [模擬程式規範.md](模擬程式規範.md) |
| `Versions/` | 各版本的 Source、Config、Simulator 備份與 `version_manifest` | [模擬程式規範.md](模擬程式規範.md) |

- `文件/{GameID}/` 只放送驗標的，外層文件不得複製進去。
- 範例：`H026_彩罐熱舞 1000/`。
