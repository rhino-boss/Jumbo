# Landbase 轉製 系統機制

本頁說明 Landbase 轉製遊戲的新手體驗、老手救援與系統限制。RTP 配置與 Link 彩金見[數學文件規範](數學文件規範.md)；未覆寫者沿用 Omniplay（見[導覽](導覽.md)）。

## 1. 新手體驗

轉製遊戲沿用 Omniplay 的新手體驗 D 版，完整說明見 [機制說明.md](../機制說明.md)。轉製時要用到的規則如下。

### 1.1 判定與倍數

新手期在固定回合檢查從第 1 轉起的累積 RTP，依區間把該轉得分改成指定倍數：

| 判定回合 | 累積 RTP | 該轉得分 |
|---|---|---:|
| 第 50 轉 | `< 50%` | 15× |
| 第 50 轉 | `50%～< 70%` | 10× |
| 第 50 轉 | `70%～< 100%` | 0× |
| 第 50 轉 | `≥ 100%` | 不處理 |
| 第 150 轉 | `< 65%` | 30× |
| 第 150 轉 | `65%～< 85%` | 15× |
| 第 150 轉 | `≥ 85%` | 不處理 |

- 指定倍數**取代**該轉原始得分，不是額外加上。
- 第 150 轉的累積 RTP 包含第 50 轉改寫後的結果。

### 1.2 轉製遊戲要注意的地方

- 只給新手 Profile，RTP 預算 2.00%；老手為 0%。
- 新手 Total RTP 97.00% ＝ Game 95.00% ＋ 新手體驗 2.00%；數學模型只負責 Game RTP，新手體驗的派彩計算與驗證時必須和 Game RTP 分開統計。
- 遊戲必須能在判定回合產生 15×、10×、0×、30× 的結果，且演出與自然得分無法區分；做法依 Omniplay [腳本規範.md](../腳本規範.md) 的新手體驗腳本，或由 Card System 重骰產生。
- 新手期不得拉 Link 彩金（第 3 節），新手體驗給出的得分也不得觸發 Link 事件。

## 2. 老手救援

- Landbase 轉製遊戲**不啟用**老手救援，RTP 固定 0%（主流遊戲為 0.50%）。
- Config、Simulator 與 Demogame 不得出現老手救援的設定或演出。

## 3. 系統限制

| 限制 | 規則 |
|---|---|
| 新手標籤 | 玩家仍帶有新手標籤時，**任何 Bet Mode（含 BF／SF）都不得拉 Link 彩金**；不得因為購買 Feature 而繞過新手限制。 |
| 新手期 | 新手期不得拉彩金，Link RTP 必為 0%；`>= $2` 時只滾 Inrc、不中彩。 |
| 低注 | `bet_tier_amount < $2` 不得拉 Link 彩金，新手、老手皆同；NB／EB 以實際押注、BF／SF 以反推基礎押注判定。 |
| 系統最大賠付 | **單把派彩上限 `$10,000,000`，超過整把重骰**。BG／FG 另有單把上限，規則見 Omniplay [天花板說明.md](../天花板說明.md)；數學模型必須依該文件驗算倍率上限，並在數學文件明記。 |

- Link 資格一律由系統依 Profile 與 `bet_tier_amount` 判定；`link_enabled = false` 時不得只把派彩改成 0，結果中不得出現已觸發但不派彩的 Link 事件或演出（同 Omniplay 數學模型規範第 2.3.1 節）。

## 4. 檢查清單

- [ ] 新手（含 BF／SF）與低注的 Link RTP 為 0%，且結果中無已觸發但不派彩的 Link 事件。
- [ ] 老手救援未啟用，Config 無相關設定。
- [ ] 倍率上限已依天花板說明驗算（BG、FG、系統賠付上限）並記錄。
