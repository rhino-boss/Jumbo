# Landbase 轉製 送驗規範

本頁說明 **Landbase 轉製遊戲**（Game ID `102xxx`／`105xxx`）的送驗包內容與各文件要注意的地方。轉製遊戲的數學與文件來自 Landbase 原機團隊；本頁未提到的製作細節沿用 Omniplay [送驗文件規範.md](../Omniplay/送驗文件規範.md)。

本頁內容與送驗根目錄 `送驗規範.md` 的「Landbase 轉製遊戲」章相同，修改時兩邊同步。

## 1. 代號對應

Landbase 遊戲用 `A0xx`／`S0xx`／`AS0xx` 代號，轉線上後改用 `H0xx` ParSheet ID 與 6 碼 Game ID。

| Landbase | ParSheet ID | Game ID | 遊戲 |
|---|---|---|---|
| A030 | H009R | 105005 | Jin Feng Fei Wu 金鳳飛舞 |
| A031 | H010R | 105006 | Hua Hao Yue Yuan 花好月圓 |

- 同一套數學可對應多個 Game ID（`H0071` → 105001／105003）。
- 對應關係以 `iGaming 遊戲代號一覽.xlsx` 為準；查不到不得逕行送驗。
- Landbase 本身若另出菲律賓版，會再立新代號（A009 → A028、A010 → A029），**不要與線上版混用**。

## 2. 送驗包內容與注意事項

| 文件 | 檔名 | 注意事項 |
|---|---|---|
| Game Description | `{GameID}_Game Description.docx`、`{GameID}_Game Description_No Progressive.docx` | 基本上都要兩份，只差彩金章節（No Progressive 規則見 Omniplay 送驗文件規範 2.5）；自既有核准模板重做為**單一英文版**，不得沿用 Landbase 的雙語檔（`{ID}-GAME DESCRIPTION - CH.docx`／`- ENG.docx`）；檔名改為 `{GameID}_` 底線前綴，不用 Landbase 的連字號、全大寫 |
| 數學說明文件 | `{GameID}_Game Document Description.docx` | Landbase 團隊交付的 DOCX，說明 PARsheet 各選項；內容須與 `PARsheet/` 的選項逐一對應 |
| `PARsheet/` | `H0xxR_Opt01.xlsx`～`_Opt06.xlsx`（RTP 選項 × 有無彩金），或 `H011194`／`H011196`／`H011294`… 的「變體＋RTP」命名 | 須有 Overview 六項必要資訊（BG／FG／Bonus／Link RTP、免費遊戲週期、JP 符號出現率）；Landbase 簡易 PARsheet（只分「單機遊戲」／「彩金遊戲」）不足時要補齊 |
| `Simulator/` | 不放 | 沒有不算缺漏；Landbase 的模擬資產另放 `simulation/`（第 3 節） |
| SHA1 清單 | `{GameID}_SHA1.txt` | 必要 |

- RTP 版本數通常 4～6 個（RTP 選項 × 有無彩金），每個版本都要有對應的 PARsheet。
- 歷史例外：102002（260427 批次）的檔名為 `102002 Game Description.docx`（空格）且無數學說明文件，屬早期交付，不作為新案依據。

## 3. 打包

送驗包只有**一個 zip**，不再另建 `{GameID}_note/`：送驗文件與 Landbase 轉來的模擬資產全部放進 `{GameID}/`，打包成 `{GameID}.zip`（另存 `備份/{GameID}_YYMMDD.zip`）。

```text
{GameID}/
├─ {GameID}_Game Description.docx
├─ {GameID}_Game Description_No Progressive.docx
├─ {GameID}_Game Document Description.docx
├─ {GameID}_SHA1.txt
├─ PARsheet/
├─ flowcharts/
└─ simulation/
   ├─ A0xx-Way Game.ipynb
   ├─ BallTable.xlsx / StripTable.xlsx / GameFeature.xlsx / Pays.xlsx
   ├─ DefineSymbols.py
   └─ common/
```

- `flowcharts/` 放流程圖（`01_base_game.png`、`02_hs_phase1.png`…）；`A0xx-Way Game.ipynb` 是 Landbase 原始模擬 notebook；`common/` 放 `DataExport.py`、`InputSettings.py`。
- `LLF_Calculator (H5).xlsx` 這類帶 `(H5)` 的計算器屬線上版專用，放 `PARsheet/`。
- `{GameID}_SHA1.txt` 涵蓋 zip 內所有檔案（清單本身除外），每次打包前重產，且一起打包進 zip。
- **`__pycache__/` 一律清掉**：105005、105006、106004 的送驗包都曾夾帶編譯中間檔，那是機器與 Python 版本相依的產物，不該進認證範圍。
- `.ipynb` 若與交付的 `.py` 內容不同步，兩者都不可交付；先確認哪一份是正式版。

## 4. 轉製後必須重新確認的內容

- **RTP 口徑**：Landbase 的 RTP 可能不含彩金；轉線上後重新拆成 **Game／Link** 兩項（不拆 Bonus），Game List 的 `BASE GAME RTP%` 與報告的客戶計算 RTP 一致（排除 Link）。
- **彩金敘述**：Landbase 彩金機制與線上 OP Jackpot 不同，Game Description 的彩金章節須改寫為 OP Jackpot 版本，不可沿用。
- **盤面與得分方式**：`Way Game`／`Line Game` 的描述要與線上 Game Rule 一致。
- **禁止內容**：Landbase 文件可能含下列內容，送驗包所有文件（Game Description、Game Document Description、PARsheet）一律不得出現；以不分大小寫搜尋，含表格儲存格，找到即為錯誤，必須移除後才可送驗。

| 檢查項目 | 關鍵字 |
|---|---|
| Extra Bet 敘述 | `extra bet` |
| Buy Feature 敘述 | `buy feature` |
| Super Feature 敘述 | `super feature` |
| >$2 拉彩金門檻 | `>$2`、`> $2`、`bet $2`、`$2 or more`、`more than $2` |
| 新手卡組內容 | `newbie`、`新手` |

- 新手卡組屬內部營運機制，不隨遊戲送驗：PARsheet 的新手工作表／欄位、文件內的新手敘述一律移除。

- [ ] Game Description 已重做為單一英文版，非沿用 Landbase 雙語檔。
- [ ] PARsheet 為完整版，Overview 必要欄位齊全，非簡易 PARsheet。
- [ ] 送驗文件與模擬資產已放進同一個 `{GameID}.zip`，SHA1 清單已重產並一起打包，`__pycache__/` 已清除。
- [ ] RTP 已重新拆成 Game／Link；彩金敘述已改為 OP Jackpot 版本。
- [ ] 第 4 節的禁止內容已全部移除。
