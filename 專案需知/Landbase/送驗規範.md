# Landbase 轉製 送驗規範

送驗文件的製作沿用 Omniplay [送驗文件規範.md](../送驗文件規範.md)：該規範描述的是 **OP 遊戲**（線上自製，Game ID `101xxx`）的完整組合。**Landbase 轉製遊戲**（Game ID `102xxx`／`105xxx`）的數學與文件來自 Landbase 原機團隊，組合不同，本頁只列差異。

本頁內容與送驗根目錄 `送驗規範.md` 的「Landbase 轉製遊戲」章相同，修改時兩邊同步。

## 1. 代號對應

Landbase 遊戲用 `A0xx`／`S0xx`／`AS0xx` 代號，轉線上後改用 `H0xx` ParSheet ID 與 6 碼 Game ID。

| Landbase | ParSheet ID | Game ID | 遊戲 |
|---|---|---|---|
| A030 | H009R | 105005 | Jin Feng Fei Wu 金鳳飛舞 |
| A031 | H010R | 105006 | Hua Hao Yue Yuan 花好月圓 |

- 同一套數學可對應多個 Game ID（`H0071` → 105001／105003）。
- 對應關係以 `iGaming 遊戲代號一覽.xlsx` 為準；查不到不得逕行送驗。
- Landbase 本身若另出菲律賓版，會再立新代號（A009 → A028、A010 → A029），**不要與線上版混用**。

## 2. 送驗包與 OP 遊戲的差異

| 項目 | OP 遊戲 | Landbase 轉製遊戲 |
|---|---|---|
| Game Description | `{GameID}_Game Description.docx` 一份（送驗版） | `{GameID}_Game Description.docx`；有彩金／無彩金兩版時另加 `{GameID}_Game Description_No Progressive.docx`（兩份只差彩金章節） |
| 數學說明文件 | `{GameID}_Math Document Description.md`＋`_EN.md`（Markdown 雙語） | `{GameID}_Game Document Description.docx`（Landbase 團隊交付的 DOCX，說明 PARsheet 各選項） |
| `PARsheet/` 內容 | 數學模型送驗版，每個 RTP 一份：`H0xx192.xlsx`、`H0xx194.xlsx`（含基礎 `H0xx1.xlsx` 時一併放入） | Landbase PARsheet 依選項分檔：`H0xxR_Opt01.xlsx`～`_Opt06.xlsx`（RTP 選項 × 有無彩金），或 `H011194`／`H011196`／`H011294`… 的「變體＋RTP」命名 |
| `Simulator/` | 必要：`Simulator.py`＋各 RTP `config_*.js`（`config.js` 基礎檔若有也放入） | **不放入送驗包**；Landbase 的模擬 notebook、輪帶／球表 xlsx、流程圖等歸 `{GameID}_note/`，不是認證標的 |
| SHA1 清單 | `{GameID}_SHA1.txt` | `{GameID}_SHA1.txt`（同樣必要） |
| RTP 版本數 | 通常 2（92／94） | 通常 4～6（RTP 選項 × 有無彩金） |

- 轉製遊戲的 Game Description 仍須依 Omniplay 送驗文件規範第 2 節，自既有核准模板重做為單一英文版，**不得沿用 Landbase 的雙語檔**（`{ID}-GAME DESCRIPTION - CH.docx`／`- ENG.docx`）；檔名也要從 Landbase 的連字號、全大寫改為 `{GameID}_` 底線前綴。
- 轉製遊戲的 PARsheet 為 Landbase 交付的版本，仍須滿足 Omniplay 送驗文件規範第 4.1 節 Overview 的六項必要資訊（BG／FG／Bonus／Link RTP、免費遊戲週期、JP 符號出現率）；Landbase 簡易 PARsheet（只分「單機遊戲」／「彩金遊戲」）不足時要補齊。
- 轉製遊戲沒有 `Simulator/` 不算缺漏；OP 遊戲缺 `Simulator/` 才是缺漏。
- 歷史例外：102002（260427 批次）的檔名為 `102002 Game Description.docx`（空格）且無數學說明文件，屬早期交付，不作為新案依據。

## 3. 模擬資產的歸屬

Landbase 轉來的模擬資產**放 `{GameID}_note/`，不是送驗標的**：

```text
{GameID}_note/
├─ flowcharts/
└─ simulation/
   ├─ A0xx-Way Game.ipynb
   ├─ BallTable.xlsx / StripTable.xlsx / GameFeature.xlsx / Pays.xlsx
   ├─ DefineSymbols.py
   └─ common/
```

- `flowcharts/` 放流程圖（`01_base_game.png`、`02_hs_phase1.png`…）；`A0xx-Way Game.ipynb` 是 Landbase 原始模擬 notebook；`common/` 放 `DataExport.py`、`InputSettings.py`。
- `LLF_Calculator (H5).xlsx` 這類帶 `(H5)` 的計算器屬線上版專用，放 `PARsheet/`。
- **`__pycache__/` 一律清掉**：105005、105006、106004 的送驗包都曾夾帶編譯中間檔，那是機器與 Python 版本相依的產物，不該進認證範圍。
- `.ipynb` 若與交付的 `.py` 內容不同步，兩者都不可交付；先確認哪一份是正式版。

## 4. 轉製後必須重新確認的內容

- **RTP 口徑**：Landbase 的 RTP 可能不含彩金；轉線上後依 OP Jackpot 口徑重新拆成 Game／Bonus／Link，Game List 的 `BASE GAME RTP%` 與報告的客戶計算 RTP 一致（排除 Link）。
- **彩金敘述**：Landbase 彩金機制與線上 OP Jackpot 不同，Game Description 的彩金章節須改寫為 OP Jackpot 版本，不可沿用。
- **盤面與得分方式**：`Way Game`／`Line Game` 的描述要與線上 Game Rule 一致。
- **禁止內容**：Landbase 文件可能含 Omniplay 送驗文件規範第 1.3 節禁止的 Extra Bet／Buy Feature 敘述與 `>$2` 門檻，必須移除。
