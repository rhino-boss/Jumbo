# Landbase 轉製 數學文件規範

本頁說明 Landbase 轉製遊戲的數學調性、RTP 配置、Link 彩金與數學模型的調整。新手體驗與系統限制見[系統機制](系統機制.md)；未覆寫者沿用 Omniplay [數學模型規範.md](../數學模型規範.md)（見[導覽](導覽.md)）。

## 1. 數學調性

- 目前**沒有明確方向，由負責人自由發揮**（待討論）。
- 自由發揮不代表免記錄。負責人決定調性後，必須在數學模型的 `Game Description` 工作表與 `game_rule.md` 寫明：
  - 以原機數學為底還是重新設計；若以原機為底，記錄原機 RTP（Game List 的「RTP 版本」欄，例：84%）與調整到線上目標 RTP 的方式（改輪帶、改 Paytable、Card System 或其他）。
  - 波動度／最大倍數目標與 Hit Rate 目標。
  - 是否啟用 Card System；啟用時依第 4 節。
- 原機既有的 Bonus／Feature 玩法屬於 Game RTP 的一部分，不另拆 Bonus Game RTP（見第 2 節）。

## 2. RTP 配置

### 2.1 配置口徑

```text
Total RTP = Link RTP + Game RTP + 新手體驗 RTP
```

- 轉製遊戲**不拆 Bonus Game RTP**；試算表「轉製遊戲」欄的 Bonus／Game 為同一合併欄位，原機的 Bonus／Feature 派彩全部歸入 Game RTP。
- 老手救援 RTP 固定 `0.00%`；Landbase 轉製遊戲不啟用老手救援（見[系統機制](系統機制.md)）。
- Inrc 不計入玩家 Total RTP；定義見第 3 節。
- 其餘口徑（RTP ＝ Total Win ÷ 實際 Total Bet、產品顯示可四捨五入但計算用完整精度、各 Bet Mode 分母用該模式實際成本）沿用 Omniplay 數學模型規範第 1.4.1 節。

### 2.2 NB／EB RTP 配置

| Player Profile | 押注層級 | 判定金額 | Link RTP | Game RTP | 新手體驗 RTP | 老手救援 RTP | Total RTP | Inrc |
|---|---|---:|---:|---:|---:|---:|---:|---|
| 新手 | 低注 | `< $2` | 0.00% | 95.15% | 2.00% | 0.00% | 97.15% | 不滾 |
| 新手 | 高注 | `>= $2` | 0.00% | 95.15% | 2.00% | 0.00% | 97.15% | 滾 0.85% |
| 老手 | 低注 | `< $2` | 0.00% | 96.50% | 0.00% | 0.00% | 96.50% | 不滾 |
| 老手 | 高注 | `>= $2` | 2.00% | 94.50% | 0.00% | 0.00% | 96.50% | 滾 0.85% |

- 押注層級只分 **`< $2`／`>= $2` 兩級**，沒有 Omniplay 的小／中／大 Bet 三級與 `> $100` 門檻。
- 新手不論層級 Link RTP 皆為 0%；新手 `>= $2` 的 0.85% 只滾入彩池、不可中彩（見[系統機制](系統機制.md)的系統限制）。
- 老手 `>= $2` 的 Game RTP 比 `< $2` 低 2 個百分點，差額即 Link RTP，兩級 Total 相同。

### 2.3 BF／SF RTP 配置

| Player Profile | 押注層級 | 判定金額 | Link RTP | Game RTP | Total RTP |
|---|---|---:|---:|---:|---:|
| 新手 | 不分層級 | 全部 | 0.00% | （試算表為 0%，待確認） | （待確認） |
| 老手 | 低注 | `< $2` | 0.00% | 96.50% | 96.50% |
| 老手 | 高注 | `>= $2` | 2.00% | 94.50% | 96.50% |

- BF／SF 的押注層級依 Omniplay 數學模型規範第 1.4.3 節，以 **Feature 購買價格 ÷ Feature Price 倍數反推的基礎押注**判定，不用購買總價。
- 試算表新手列的 BF／SF Total RTP 為 0%。新手若可購買 BF，其 Game RTP 待確認；但不論結果如何，**新手 BF 的 Link RTP 必為 0%**。
- 老手 BF／SF 的 Game RTP 與 NB 相同層級一致（96.50%／94.50%），不是 Omniplay 的 92.50% 固定值。

### 2.4 與 Omniplay 主流配置的差異

| 項目 | Omniplay 主流 | Landbase 轉製 |
|---|---|---|
| RTP 拆分 | Link + Bonus Game + Game | Link + Game（Bonus 併入 Game） |
| 押注層級 | 小／中／大 Bet（`< $2`、`$2～$100`、`> $100`） | 低／高注（`< $2`、`>= $2`） |
| 新手 Total RTP（NB） | 95.00%（Bonus 2% + Game 93%）＋新手體驗 2% | 97.15%（Game 95.15% + 新手體驗 2%） |
| 老手 Total RTP | 96.50%（含老手救援 0.50%） | 96.50%（老手救援 0%） |
| 老手 BF／SF Game RTP | 92.50% 固定 | 與 NB 同層級相同（96.50%／94.50%） |
| 倍率權重套數（啟用 Card System 時） | 老手小／中／大三套 | 老手低／高注兩套（第 4 節） |

## 3. Link 彩金（Grand／Major）

Link 彩金為 Grand、Major 兩層累積彩池，參數依上線區域不同（試算表 `彩金參數` 頁，2026/05/14）：

| Area | Grand 起始彩池 | Major 起始彩池 | Grand RTP | Major RTP | Grand Inrc | Major Inrc | 備註 |
|---|---:|---:|---:|---:|---:|---:|---|
| Online（小平台） | $100,000 | $20,000 | 1.00% | 1.00% | 0.35% | 0.50% | |
| Online | $500,000 | $100,000 | 1.00% | 1.00% | 0.35% | 0.50% | |
| Okada | $1,000,000 | $100,000 | 1.30% | 0.70% | 0.20% | 0.20% | MFB 群組 |

- Link RTP 2.00% ＝ Grand 1.00% ＋ Major 1.00%（Okada 為 1.30% ＋ 0.70%）；Inrc 0.85% ＝ Grand 0.35% ＋ Major 0.50%（Okada 為 0.40%）。
- Inrc（Increment，彩池增量）是押注中滾入 Link 彩池的比例，**不計入玩家 Total RTP**。
- 「可滾 Inrc」表示該局押注會依 Inrc 比例滾入彩池；「可拉 Link」表示該局有資格中 Grand／Major。兩者是不同的資格，對照見第 2.2 節與[系統機制](系統機制.md)的系統限制。
- Link RTP 與 Inrc 由系統層依 Area 設定，數學模型不得把彩金參數寫死在輪帶或 Paytable；模型只負責 Game RTP 與新手體驗，並在 `Game Description` 記錄採用的 Area 參數版本。
- 數學模型必須定義哪些派彩歸入 Link、哪些歸入 Game，不得重複計算。

## 4. Card System 的層級調整

啟用 Card System 時，Oldhand 的押注層級只有兩套：

```text
oldhand
├─ normal_bet    → low_bet／high_bet → weight_bg／weight_fg
├─ extra_bet     → low_bet／high_bet → weight_bg／weight_fg
├─ buy_feature   → low_bet／high_bet → weight_fg
└─ super_feature → low_bet／high_bet → weight_fg
```

- `low_bet` 對應 `< $2`，`high_bet` 對應 `>= $2`；不得保留 `medium_bet`／`big_bet` 的空殼設定。
- 區間工作表（`Multiplier_Weight`、`Avg_Multi`、`Nature_Prob`）的 Oldhand 欄位依低／高注命名，例如 `NB_BG_Low`／`NB_BG_High`；Newbie 欄位不變。
- 倍率上限依[系統機制](系統機制.md)的系統最大賠付反推，不直接套用 Omniplay 第 1.4.4 節的 `20000x`／`2000x` 預設；Newbie 的 `30x`／`120x` 上限沿用。
- 是否啟用 Card System 隨第 1 節數學調性決定；未啟用時不得建立空白權重欄或 Card System 設定。

## 5. 命名補充

- Landbase 轉製遊戲的 ParSheet ID 仍為 `H<三位數字>1`；同一數學供多個 Game ID 使用時（如 `H0111` → 102001／102002），數學模型只建一份，Game ID 對應記錄於 `Game Description` 工作表與 Game List。

## 檢查清單

- [ ] 已確認數學調性並記錄於 `Game Description`（原機為底或重新設計、目標 RTP、波動度、是否啟用 Card System）。
- [ ] RTP 配置採第 2 節（Link + Game + 新手體驗），且與試算表「轉製遊戲」欄當前版本一致，已記錄引用日期。
- [ ] 押注層級只有 `< $2`／`>= $2` 兩級；Config、Simulator、Demogame 無小／中／大 Bet 殘留。
- [ ] 採用的 Link 彩金 Area 參數版本已記錄；數學模型未寫死彩金參數。
- [ ] Omniplay 數學模型規範第 1.6 節其餘檢查項目全部通過。
