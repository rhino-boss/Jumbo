# Mine 總覽

本站是自己用的開發規範（要產出什麼、長什麼樣），**不同步給其他人**。開發順序見「開發流程」；各產線的規範見 Omniplay／Landbase／Reskin。開新專案先讀開發流程第 4 節，再讀該步驟對應的規範。

## 1. 文件

| 文件 | 內容 |
|---|---|
| [產出與紀錄規範](開發規範/產出與紀錄規範.md) | 每個專案必須產出的文件、`修改紀錄.md` 格式、專案目錄與存放位置 |
| [GameRule規範](開發規範/GameRule規範.md) | `game_rule.md` 的固定章節骨架、必要欄位與交付檢查 |
| [模擬程式規範](開發規範/模擬程式規範.md) | Simulator 架構、批次、Console 與報表格式；Config 轉檔、驗證與版本 |
| [Demogame規範](開發規範/Demogame規範.md) | Demogame 載入、共用／By Game 區域、補牌、Debug、對帳；Demo 版 RTP 120% |
| [提案報告規範](開發規範/提案報告規範.md) | 提案說明簡報（.pptx）的章節與版式 |
| [數值報告規範](開發規範/數值報告規範.md) | 本作與競品、前作的差異分析報告 |
| [Demo報告規範](開發規範/Demo報告規範.md) | 給內部與客戶說明設計理由的 Demo 報告 |
| [專有名詞](開發規範/專有名詞.md) | 常用名詞解釋 |

## 2. 資料夾與網頁

| 位置 | 內容 | 同步 |
|---|---|---|
| `開發規範/Omniplay/`、`Landbase/`、`Reskin/` | 各產線規範 | Omniplay 發佈到團隊共享區；Landbase／Reskin 同步到 SVN 說明書（只更新已放入的檔） |
| `開發規範/*.md` | 本站（Mine） | 不同步 |
| `開發流程/` | 開發流程 | 不同步 |
| `其他/` | `_build_html.py` 等工具 | — |

- 任何 `.md` 改完，同一次修改內在 `其他/` 執行 `py _build_html.py`，重建 `專案需知/` 最外層的網頁與入口 `igaming_specification.html`；不得手改 HTML。
- 三產線互不提及對方的數值；產線資料夾只放自己的文件。
